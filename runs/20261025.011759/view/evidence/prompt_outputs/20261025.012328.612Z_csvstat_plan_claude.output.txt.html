| Field       | Value |

| Provides    | rows, nulls, distinct |
| Consumes    | internal/profile.IsNull |

## Questions

- None.

## Purpose

Give every column three counts used by the profile table. The counts are computed from the file examined and never hardcoded.

## Behavior

- `rows` is the number of data records, that is, every record after the header. It is the same for every column.
- `nulls` is the number of values in the column for which `internal/profile.IsNull` is true.
- `distinct` is the number of different non-null values, compared as exact trimmed strings. Case is significant: `true` and `TRUE` are two values. Null values are never counted.
- A file with a header and no records yields `rows` 0, `nulls` 0, and `distinct` 0 for every column.

## Interface

- Package `internal/profile` exposes a function that takes a column's trimmed values and returns the three counts.
- The project test suite in `internal/profile` carries tests named `TestCountsRows`, `TestCountsNulls`, `TestCountsDistinct`, and `TestCountsHeaderOnly`, written by the implementer against real output.

# FEATURE: MinMax

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Report the minimum and maximum for every column type. |
| Depends On  | FEATURE-TypeDate.md, FEATURE-TypeOther.md |
| Provides    | min, max |
| Consumes    | internal/profile.InferType |

## Questions

- None.

## Purpose

Give every column a `min` and `max` appropriate to its inferred type.

## Behavior

Statistics consider non-null values only.

| Type | min | max |
|---|---|---|
| `integer` | smallest value, written as a plain integer | largest value, written as a plain integer |
| `number` | smallest value, exactly two decimals | largest value, exactly two decimals |
| `date` | earliest date | latest date |
| `boolean` | `false` if any value is false, else `true` | `true` if any value is true, else `false` |
| `text` | smallest by byte value | largest by byte value |
| `empty` | empty string | empty string |

- Integer and number comparison is numeric and exact, using `math/big`. Values such as `-3` and `12` compare as numbers, not strings.
- Boolean values compare ignoring case, and the written result is lowercase.
- Number output has a leading `-` when negative, no thousands separator, and is rounded once half away from zero from the exact value.

## Interface

- Package `internal/profile` computes `min` and `max` strings for a column given its type and values.
- The project test suite in `internal/profile` carries tests named `TestMinMaxInteger`, `TestMinMaxNumber`, `TestMinMaxDate`, `TestMinMaxBoolean`, `TestMinMaxText`, and `TestMinMaxEmpty`.

# FEATURE: SumMean

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Compute the exact sum and mean of numeric columns, rounded once half away from zero. |
| Depends On  | FEATURE-TypeNumeric.md |
| Provides    | sum, mean |
| Consumes    | internal/profile.InferType |

## Questions

- None.

## Purpose

Give `integer` and `number` columns an exact `sum` and `mean`, free of floating point error.

## Behavior

- Arithmetic uses `math/big` (`big.Rat`) over non-null values. Rounding happens once, when writing.
- `integer` sum is the integer total written as a plain integer.
- `number` sum is written with exactly two decimal places.
- `mean` for `integer` and `number` is the total divided by the non-null count, written with exactly two decimals.
- Rounding is half away from zero from the exact value. A negative result has a leading `-`; there is no thousands separator.
- A numeric column with no non-null values is typed `empty`, so it never reaches sum or mean.
- For every other type `sum` and `mean` are empty strings.

## Interface

- Package `internal/profile` exposes a formatter that renders a `big.Rat` with two decimals, rounded half away from zero, and computes sum and mean strings for a typed column.
- The project test suite in `internal/profile` carries tests named `TestSumInteger`, `TestSumNumber`, `TestMeanRounding`, `TestMeanNegative`, and `TestSumMeanNonNumeric`.

# FEATURE: ProfileOutput

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Write the profile table with one row per column in file order. |
| Depends On  | FEATURE-Counts.md, FEATURE-MinMax.md, FEATURE-SumMean.md, FEATURE-Median.md, FEATURE-TypeDate.md, FEATURE-TypeOther.md |
| Provides    | profile table on standard output |
| Consumes    | internal/profile |

## Questions

- None.

## Purpose

Assemble the per-column type and statistics into the CSV table the command writes when profiling a file.

## Behavior

- With a file argument and no `--freq`, write the header `column,type,rows,nulls,distinct,min,max,sum,mean,median`.
- Then write one row per column in file order, using the trimmed header name.
- Output uses `encoding/csv`'s writer with `\n` line endings, so a field containing a comma, a double quote, or a newline is quoted per RFC 4180.
- The command exits 0 on success.
- On any failure nothing is written to standard output; the table is built fully before the first byte is written.

## Interface

- `internal/cli.Run` calls the reader, null classifier, type inference, and the statistics, then writes the table to its `stdout` writer.
- The project test suite carries `TestProfileHeader`, `TestProfileRowOrder`, and `TestProfileQuoting` in `internal/cli`.

import csv
import io
import math
import os
import tempfile
from fractions import Fraction

from drydock_go import cli_runner


def fmt(fr):
    n = math.floor(abs(fr) * 100 + Fraction(1, 2))
    s = f"{n // 100}.{n % 100:02d}"
    return "-" + s if fr < 0 and n != 0 else s


header = ["id", "amt", "when", "flag", "word", "gone"]
records = [
    ["3", "1.50", "2025-01-05", "true", "pear", "NA"],
    ["1", "-2.25", "2024-12-31", "FALSE", "apple", ""],
    ["2", "10.00", "2025-03-01", "true", "pear", "null"],
    ["10", "N/A", "2025-02-14", "true", "fig", "NULL"],
    ["7", "4.75", "NA", "false", "apple", "N/A"],
]
cols = list(zip(*records))

with tempfile.TemporaryDirectory() as tmp:
    path = os.path.join(tmp, "data.csv")
    with open(path, "w", newline="") as fh:
        w = csv.writer(fh)
        w.writerow(header)
        w.writerows(records)
    code, out, err = cli_runner(path)

print(out)
print(err)
assert code == 0, (code, out, err)
rows = list(csv.reader(io.StringIO(out)))
assert rows[0][0] == "column"
assert [r[0] for r in rows[1:]] == header

nulls = {"", "na", "n/a", "null"}


def nonnull(col):
    return [v for v in col if v.strip().lower() not in nulls]


by = {r[0]: r for r in rows[1:]}

ids = [Fraction(int(v)) for v in nonnull(cols[0])]

assert r[1] == "integer"

amts = [Fraction(v) for v in nonnull(cols[1])]

assert r[5] == fmt(min(amts))

assert r[7] == fmt(sum(amts))
assert r[8] == fmt(sum(amts) / len(amts))
s = sorted(amts)
mid = len(s) // 2
med = s[mid] if len(s) % 2 else (s[mid - 1] + s[mid]) / 2
assert r[9] == fmt(med)

dates = nonnull(cols[2])
