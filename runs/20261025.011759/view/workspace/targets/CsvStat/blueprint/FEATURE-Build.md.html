FEATURE: Build Executable

FieldValue
Version20261025 V1
DescriptionThe csvstat executable builds from the application root with go build using only the standard library.
Depends OnARCHITECTURE.md
Providescsvstat executable
Consumesinternal/cli.Run

Purpose

go build -o <path> ./cmd/csvstat succeeds from the application root and produces the csvstat executable. main passes os.Args[1:], os.Stdout, and os.Stderr to cli.Run and exits with the returned code. The supplied grader builds the executable this way.

Trigger

A developer or the grader runs go build -o <path> ./cmd/csvstat.

Behavior

  • The module is Go 1.22 or newer and imports only the standard library and its own packages.
  • main is the only caller of os.Exit.
  • The built binary is runnable and exits with the code cli.Run returns.

Programmatic Acceptance

=== AC build-go-build ===
Intent: go build of ./cmd/csvstat succeeds and writes an executable file.
Requires: executable=go; scope=test

import os import subprocess import sys import tempfile

with tempfile.TemporaryDirectory() as work: target = os.path.join(work, "csvstat") result = subprocess.run( ["go", "build", "-o", target, "./cmd/csvstat"], capture_output=True, text=True, ) print(result.stdout) print(result.stderr, file=sys.stderr) assert result.returncode == 0 assert os.path.isfile(target) assert os.access(target, os.X_OK) === END AC build-go-build ===
