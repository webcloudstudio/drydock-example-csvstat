FEATURE: Test Runner

FieldValue
Version20261025 V1
DescriptionProvide the POSIX bin/test.sh that runs go vet and go test and exits zero only when both pass.
Depends OnFEATURE-FrequencyTop.md, FEATURE-ColumnSelect.md, FEATURE-ReadFailure.md, FEATURE-Build.md
Providesbin/test.sh
Consumesgo vet, go test

Purpose

bin/test.sh is the single command that gates every behavioral story. The project's own Go test suite is written beside the code and covers each type, each statistic, null handling, rounding, each output form, and each exit code, using files the tests write themselves.

Behavior

  • POSIX sh only; no bashisms. It changes to the application root (the directory above bin/) so it

works from any current directory.

  • It runs go vet ./... and then go test ./..., and exits zero only when both succeed. A failure

of go vet stops the script with a non-zero status.

  • Tests call cli.Run(args, &stdout, &stderr) with bytes.Buffer writers and write their fixture

files under t.TempDir(). They never read sources/run.sh.

  • The suite covers: each of the five types, min/max per type, sum/mean/median, half-away-from-zero

rounding including negatives, null classification, quoting of fields with commas, frequency ordering and --top, and exit codes 1, 2, and 3.
