Planning Instructions

Delivery Shape

csvstat is a CLI. Input: one CSV file path plus optional --column, --freq, and --top flags. Output: profile or frequency CSV on standard output, with one stderr diagnostic per failure. Exit codes are 0 success, 1 unreadable file, 2 usage error, 3 rejected input. Execution is single-pass: read, validate, infer types, then compute the requested profile or frequency list. There is no persistence, network use, or configuration file.

Test and Acceptance Strategy

  • Focused story tests: each feature story runs go test for the slice it owns, with fixture files written by the test, and declares Suite: scoped. No feature story runs sources/run.sh.
  • Terminal verification: BUILD-003 is the only story that runs the full conformance harness. It depends on every implementation story, declares Suite: full, and runs sh sources/run.sh. run.sh accepts no scope selector, so no story runs it partially.
  • Sea Trial st-001 is the same full proof at project level.
  • BUILD-002 is proved by a scoped test that runs bin/test.sh against a temporary module, not by the supplied harness.

Source Conflicts and Gaps

  • No cross-source conflicts. INSTRUCTIONS.md and run.sh agree on command forms, exit codes, the 22-check count (4 + 3 + 5 + 4 + 6), and the stdout contract.
  • Spot checks of run.sh known answers against the fixtures agree: employees id sum 24300, manager_id (9 non-null values, sum 30, mean 3.33, median 4.00), notes nulls 10, the department frequency counts, and orders customer distinct 5 with Globex at 10.
  • Unattended resolutions, persisted here for planning:
    1. No --help flag. --help is an unknown option and exits 2 (AC-002).
    2. Invalid UTF-8 is not a rejection condition, because the brief's rejection list is exhaustive (AC-001).
    3. Integer and decimal totals use exact arithmetic (AC-004).
    4. Column and frequency names match exactly after trimming (AC-003).
    5. The two-decimal rule applies to integer mean and median as well as to number columns, as run.sh A1 shows (1012.50).
