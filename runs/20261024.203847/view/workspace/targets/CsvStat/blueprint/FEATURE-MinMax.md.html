FEATURE: Min and Max

FieldValue
Version20261024 V1
DescriptionCompute the minimum and maximum of each column according to its inferred type.
Depends OnFEATURE-TypeInference.md, FEATURE-DateType.md, ARCHITECTURE.md
Providesprofile.MinMax
Consumestyping.Infer, typing.IsDate

Purpose

Supply the min and max fields of each profile row.

Behavior

  • Extremes are taken over non-null trimmed values, using exact arithmetic (math/big) for numeric types, never floats.
  • integer: smallest and largest written as plain integers. Values beyond 64 bits are handled exactly.
  • number: smallest and largest written with exactly two decimal places, rounded half away from zero from the exact value.
  • date: earliest and latest, as written.
  • boolean: min is false if any value is false, else true; max is true if any value is true, else false. Output is lowercase.
  • text: smallest and largest by byte value of the trimmed strings.
  • empty: both blank.
  • profile.MinMax(typ string, values []string) (min, max string).

=== AC minmax-number-two-places ===
Intent: Number min and max are written with two decimal places rounded half away from zero.

import csv import io import os import tempfile from decimal import Decimal, ROUND_HALF_UP

values = ["15.27", "231.18", "2.005", "100", "7.5"] dec = [Decimal(v) for v in values] cent = Decimal("0.01") want_min = str(min(dec).quantize(cent, rounding=ROUND_HALF_UP)) want_max = str(max(dec).quantize(cent, rounding=ROUND_HALF_UP)) text = "p\n" + "\n".join(values) + "\n" with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "in.csv") with open(path, "w", newline="") as fh: fh.write(text) code, out, err = cli_runner(path) print(out) print(err) assert code == 0, (code, out, err) r = list(csv.DictReader(io.StringIO(out)))[0] assert r["type"] == "number" assert r["min"] == want_min assert r["max"] == want_max === END AC minmax-number-two-places ===

=== AC minmax-empty-and-nulls ===
Intent: An empty column has blank min and max, and nulls are excluded from extremes.

import csv import io import os import tempfile

from drydock_go import cli_runner
