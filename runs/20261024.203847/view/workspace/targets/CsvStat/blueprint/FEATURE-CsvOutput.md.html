FEATURE: CSV Output

FieldValue
Version20261024 V1
DescriptionWrite profile and frequency results as RFC 4180 CSV with newline line endings, only on success.
Depends OnFEATURE-Counts.md, FEATURE-MinMax.md, FEATURE-NumericStats.md, FEATURE-Frequencies.md, FEATURE-ColumnSelect.md
Providesoutput.WriteProfile, output.WriteFreq
Consumesprofile.Counts, profile.MinMax, profile.NumericStats, freq.Top

Purpose

Serialize the profile and frequency results to standard output.

Behavior

  1. Profile output has the header column,type,rows,nulls,distinct,min,max,sum,mean,median, then

one row per column in file order, or the single row of the column named by --column.

  1. Frequency output has the header value,count, then the ranked rows.
  2. Writing uses encoding/csv with UseCRLF false, so every line ends with \n. A field

containing a comma, a double quote, or a newline is quoted as RFC 4180 specifies.

  1. Output is buffered and written to standard output only when the whole command succeeds. A

failing command writes nothing to standard output and one diagnostic line to standard error naming the file and, for a rejected record, its line number.

  1. Empty statistic fields are written as empty strings.
