FEATURE: Frequencies

FieldValue
Version20261024 V1
DescriptionList the most frequent non-null values of one column with --freq, ordered by count then byte value.
Depends OnFEATURE-NullTrim.md, FEATURE-CliOptions.md
Providesfreq.Top
Consumesreader.Trim, reader.IsNull, --freq, --top

Purpose

With --freq <name>, csvstat lists the most frequent values of the named column instead of profiling. The command is csvstat --freq <name> [--top <n>] <file>.

Behavior

  1. The column is found by exact, case-sensitive comparison against the trimmed header names.
  2. Each value is trimmed before counting. Null values (empty, NA, N/A, NULL ignoring case)

are not listed and not counted.

  1. One row is produced per distinct non-null value, with its count.
  2. Rows are ordered by count descending, then by value ascending by byte value.
  3. At most --top rows are returned. --top defaults to 5 and is a positive integer.
  4. A column with no non-null values produces only the header row.
  5. A column name absent from the header exits 3 with nothing on standard output and one diagnostic

on standard error.

Output

Header value,count, then the ranked rows. Serialization is owned by FEATURE-CsvOutput.md; this feature supplies the ordered list of (value, count) pairs as freq.Top.

Programmatic Acceptance

=== AC freq-order-and-default-top ===
Intent: Frequencies are ordered by count descending then byte value ascending, and default to five rows.
Requires: executable=go; scope=test

import csv import io import os import tempfile from collections import Counter

from drydock_go import cli_runner

values = ["delta"] * 4 + ["alpha"] * 3 + ["charlie"] * 3 + ["bravo"] * 2 + ["echo"] + ["foxtrot"] + ["golf"] with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "data.csv") with open(path, "w", newline="") as f: w = csv.writer(f) w.writerow(["k"]) for v in values: w.writerow([v]) code, out, err = cli_runner("--freq", "k", path) print(out) print(err) assert code == 0 rows = list(csv.reader(io.StringIO(out))) assert rows[0] == ["value", "count"] counts = Counter(values) ranked = sorted(counts.items(), key=lambda kv: (-kv[1], kv[0]))[:5] assert rows[1:] == [[v, str(c)] for v, c in ranked] === END AC freq-order-and-default-top ===

User Acceptance

  • None.

Guardrails

  • Null values are never listed.
  • The ordering tie-break is byte value, not locale collation.
  • A failing command writes nothing to standard output.
