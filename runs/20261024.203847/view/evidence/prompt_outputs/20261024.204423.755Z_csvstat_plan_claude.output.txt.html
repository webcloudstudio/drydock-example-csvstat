# FEATURE: Type Inference

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Infer each column's type among integer, number, boolean, text, and empty from its non-null values. |
| Depends On  | FEATURE-NullTrim.md, ARCHITECTURE.md |
| Provides    | typing.Infer |
| Consumes    | reader.IsNull, reader.Trim |

## Questions

- None.

## Purpose

Give every column a type so later stories choose the right min, max, and numeric statistics.

## Behavior

- Inference runs over the trimmed, non-null values of one column. Null values never influence the type.
- A column takes the first of `integer`, `number`, `date`, `boolean`, `text` that every non-null value satisfies. A column with no non-null value is `empty`.
- `integer`: every value matches `-?[0-9]+`.
- `number`: every value matches `-?[0-9]+(\.[0-9]+)?`. A column mixing integer and decimal values is `number`.
- `boolean`: every value equals `true` or `false`, ignoring case.
- `text`: anything else.
- `date` is recognized by `typing.IsDate`, supplied by the date-type story. In this story the date check is a hook, `func(string) bool`, that defaults to returning false, so a column of dates is `text` until that story installs the real check. The hook sits between `number` and `boolean` in the order.
- `typing.Infer(values []string) string` takes already-trimmed values, skips nulls via `reader.IsNull`, and returns the type token.
- The profile output writes the token in the `type` column.

## Programmatic Acceptance

# FEATURE: Date Type

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Recognize date columns whose every non-null value is a real YYYY-MM-DD calendar date. |
| Depends On  | FEATURE-TypeInference.md, ARCHITECTURE.md |
| Provides    | typing.IsDate |
| Consumes    | typing.Infer |

## Questions

- None.

## Purpose

Let a column of calendar dates be typed `date`, while near-misses such as `2025-02-30` leave the column as `text`.

## Behavior

- `typing.IsDate(s string) bool` is true only when `s` matches `YYYY-MM-DD` (four, two, two digits, hyphen-separated) and names a real calendar date, leap years included.
- Validation uses `time.Parse` with layout `2006-01-02` plus a check that the formatted result equals the input, or an equivalent exact check, so no value is normalized into validity.
- The date hook in `typing.Infer` is bound to `typing.IsDate`. A column is `date` only when every non-null value satisfies it and not every value is an integer or number.
- One non-date value makes the column fall to the next matching type (`boolean` or `text`).
- Timestamps such as `2025-03-01T08:00` are not dates.

## Programmatic Acceptance

# FEATURE: Counts

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Count rows, null values, and distinct non-null values for each column. |
| Depends On  | FEATURE-NullTrim.md, ARCHITECTURE.md |
| Provides    | profile.Counts |
| Consumes    | reader.IsNull, reader.Trim |

## Questions

- None.

## Purpose

Supply the `rows`, `nulls`, and `distinct` fields of each profile row.

## Behavior

- `rows` is the number of data records (the header is not counted). A header-only file has `rows` 0 for every column.
- `nulls` is the number of values in the column that are null: empty after trimming, or equal to `NA`, `N/A`, or `NULL` ignoring case.
- `distinct` is the number of different non-null values, compared as exact strings after trimming. Comparison is case-sensitive, so `Acme` and `acme` are two values; `  Globex  ` and `Globex` are one.
- An all-null or zero-row column has `distinct` 0.
- `profile.Counts(values []string) (rows, nulls, distinct int)` takes trimmed values.

## Programmatic Acceptance

# FEATURE: Min and Max

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Compute the minimum and maximum of each column according to its inferred type. |
| Depends On  | FEATURE-TypeInference.md, FEATURE-DateType.md, ARCHITECTURE.md |
| Provides    | profile.MinMax |
| Consumes    | typing.Infer, typing.IsDate |

## Questions

- None.

## Purpose

Supply the `min` and `max` fields of each profile row.

## Behavior

- Extremes are taken over non-null trimmed values, using exact arithmetic (`math/big`) for numeric types, never floats.
- `integer`: smallest and largest written as plain integers. Values beyond 64 bits are handled exactly.
- `number`: smallest and largest written with exactly two decimal places, rounded half away from zero from the exact value.
- `date`: earliest and latest, as written.
- `boolean`: `min` is `false` if any value is false, else `true`; `max` is `true` if any value is true, else `false`. Output is lowercase.
- `text`: smallest and largest by byte value of the trimmed strings.
- `empty`: both blank.
- `profile.MinMax(typ string, values []string) (min, max string)`.

## Programmatic Acceptance

## Purpose

Supply the `sum`, `mean`, and `median` fields of each profile row for numeric columns.

## Behavior

- Applies to `integer` and `number` columns; every other type leaves all three fields blank.
- Parse non-null values into exact rationals with `math/big` (`big.Rat`). Never use floats. Integer totals cannot overflow.
- `sum`: integer columns write the plain integer total; number columns write the total with exactly two decimal places.
- `mean`: total divided by the non-null count, written with two decimal places for both integer and number columns.
- `median`: the middle of the sorted non-null values, or the mean of the two middle values when the count is even; two decimal places for both types.
- Rounding happens once, from the exact value, half away from zero. A leading `-` marks a negative result; no thousands separator.
- `profile.NumericStats(typ string, values []string) (sum, mean, median string)`.

## Programmatic Acceptance

=== AC numeric-integer-stats ===
Intent: Integer sum is a plain integer while mean and median carry two places, with an even count averaging the middle pair.

import csv
import io
import os
import tempfile
from fractions import Fraction

from drydock_go import cli_runner


def two(fr):
    neg = fr < 0
    q = int((abs(fr) * 100 + Fraction(1, 2)) // 1)
    sign = "-" if neg and q else ""
    return sign + str(q // 100) + "." + str(q % 100).zfill(2)


ints = [1, 2, 3, 10]
text = "n\n" + "\n".join(str(i) for i in ints) + "\n"
total = sum(ints)
mean = Fraction(total, len(ints))
s = sorted(ints)
mid = len(s) // 2
median = Fraction(s[mid - 1] + s[mid], 2)
with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "in.csv")
    with open(path, "w", newline="") as fh:
        fh.write(text)
    code, out, err = cli_runner(path)
print(out)
print(err)
assert code == 0, (code, out, err)
r = list(csv.DictReader(io.StringIO(out)))[0]
assert r["type"] == "integer"
assert r["sum"] == str(total)
assert r["mean"] == two(mean)
assert r["median"] == two(median)
=== END AC numeric-integer-stats ===

=== AC numeric-number-stats-rounding ===
Intent: Number sum, mean, and median are two places rounded half away from zero from the exact value, with nulls excluded.

import csv
import io
import os
import tempfile
from fractions import Fraction

from drydock_go import cli_runner


def two(fr):
    neg = fr < 0
    q = int((abs(fr) * 100 + Fraction(1, 2)) // 1)
    sign = "-" if neg and q else ""
    return sign + str(q // 100) + "." + str(q % 100).zfill(2)


raw = ["0.125", "-12.21", "29.33", "", "N/A", "2.41", "0.005", "20.98"]
nonnull = [Fraction(v) for v in raw if v not in ("", "N/A")]
total = sum(nonnull)
mean = total / len(nonnull)
s = sorted(nonnull)
mid = len(s) // 2
median = s[mid] if len(s) % 2 else (s[mid - 1] + s[mid]) / 2
text = "t\n" + "\n".join(raw) + "\n"
with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "in.csv")
    with open(path, "w", newline="") as fh:
        fh.write(text)
    code, out, err = cli_runner(path)
print(out)
print(err)
assert code == 0, (code, out, err)
r = list(csv.DictReader(io.StringIO(out)))[0]
assert r["type"] == "number"
assert r["sum"] == two(total)
assert r["mean"] == two(mean)
assert r["median"] == two(median)
=== END AC numeric-number-stats-rounding ===

=== AC numeric-blank-for-non-numeric ===
Intent: Text, boolean, and empty columns leave sum, mean, and median blank.

import csv
import io
import os
import tempfile

from drydock_go import cli_runner

cols = {
    "word": ["a", "b", "c"],
    "flag": ["true", "false", "true"],
    "none": ["", "NA", "NULL"],
}
names = list(cols)
nrows = len(cols[names[0]])
lines = [",".join(names)]
for i in range(nrows):
    lines.append(",".join(cols[n][i] for n in names))
text = "\n".join(lines) + "\n"
with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "in.csv")
    with open(path, "w", newline="") as fh:
        fh.write(text)
    code, out, err = cli_runner(path)
print(out)
print(err)
assert code == 0, (code, out, err)
rows = {r["column"]: r for r in csv.DictReader(io.StringIO(out))}
for n in names:
    assert rows[n]["sum"] == "", n
    assert rows[n]["mean"] == "", n
    assert rows[n]["median"] == "", n
=== END AC numeric-blank-for-non-numeric ===
