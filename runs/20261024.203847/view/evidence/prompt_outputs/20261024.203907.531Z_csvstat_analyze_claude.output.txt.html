## Story List

### Feature: Input Reading

| ID | Story | High-level AC |
|---|---|---|
| INPUT-001 | Read a CSV file | A UTF-8 RFC 4180 file is parsed with encoding/csv; the first record is the header, later records are data records, and a quoted comma stays inside one value. |
| INPUT-002 | Trim values and classify nulls | Header names and values are trimmed; empty, NA, N/A, and NULL ignoring case are null; all other values are non-null. |
| INPUT-003 | Reject malformed files | An empty file, an empty or repeated header name, or a ragged record exits 3, writes nothing to standard output, and the diagnostic names the file and line. |
| INPUT-004 | Report unreadable files | A file that cannot be opened or read exits 1 and writes nothing to standard output. |

### Feature: Command Line

| ID | Story | High-level AC |
|---|---|---|
| CLI-001 | Parse options and the file argument | Options precede the single required file; `--column`, `--freq`, and `--top` are accepted in the specified forms. |
| CLI-002 | Profile one named column | `--column <name>` profiles only the named column; a name absent from the header exits 3. |
| CLI-003 | Reject usage errors | A missing or extra file, unknown option, missing option value, invalid `--top`, `--top` without `--freq`, or `--column` with `--freq` exits 2 and writes nothing to standard output. |

### Feature: Column Typing

| ID | Story | High-level AC |
|---|---|---|
| TYPE-001 | Infer integer, number, boolean, text, and empty | Each column takes the first matching type among those its non-null values all satisfy; a column with no non-null values is empty. |
| TYPE-002 | Infer date columns with calendar validation | A column is date when every non-null value matches YYYY-MM-DD and is a real calendar date; `2025-02-30` is not a date. |

### Feature: Column Profile

| ID | Story | High-level AC |
|---|---|---|
| PROF-001 | Count rows, nulls, and distinct values | Each column reports rows, nulls, and distinct non-null values compared as exact trimmed strings, in file order. |
| PROF-002 | Report min and max by type | Min and max follow the type rules, including byte-order text, boolean, date, and blank values for empty columns. |
| PROF-003 | Report sum, mean, and median for numeric columns | Integer and number columns report sum, mean, and median; number and decimal statistics are rounded to two places, half away from zero; other types leave them empty. |

### Feature: CSV Output

| ID | Story | High-level AC |
|---|---|---|
| OUT-001 | Write profile and frequency output as CSV | Output uses `\n` line endings with encoding/csv quoting; a failing command writes one stderr diagnostic and nothing to stdout. |

### Feature: Value Frequencies

| ID | Story | High-level AC |
|---|---|---|
| FREQ-001 | List the most frequent values | With `--freq`, non-null values are listed by count descending then byte value ascending, at most `--top` rows (default 5); a column with no non-null values writes only the header. |

## Planning Instructions

### Delivery Shape

csvstat is a CLI. Input: one CSV file path plus optional `--column`, `--freq`, and `--top` flags. Output: profile or frequency CSV on standard output, with one stderr diagnostic per failure. Exit codes are 0 success, 1 unreadable file, 2 usage error, 3 rejected input. Execution is single-pass: read, validate, infer types, then compute the requested profile or frequency list. There is no persistence, network use, or configuration file.
