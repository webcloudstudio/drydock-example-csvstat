# FEATURE: Frequencies

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | List the most frequent non-null values of one column with --freq, ordered by count then byte value. |
| Depends On  | FEATURE-NullTrim.md, FEATURE-CliOptions.md |
| Provides    | freq.Top |
| Consumes    | reader.Trim, reader.IsNull, --freq, --top |

## Questions

- None.

## Purpose

With `--freq <name>`, csvstat lists the most frequent values of the named column instead of
profiling. The command is `csvstat --freq <name> [--top <n>] <file>`.

## Behavior

1. The column is found by exact, case-sensitive comparison against the trimmed header names.
2. Each value is trimmed before counting. Null values (empty, `NA`, `N/A`, `NULL` ignoring case)
   are not listed and not counted.
3. One row is produced per distinct non-null value, with its count.
4. Rows are ordered by count descending, then by value ascending by byte value.
5. At most `--top` rows are returned. `--top` defaults to 5 and is a positive integer.
6. A column with no non-null values produces only the header row.
7. A column name absent from the header exits 3 with nothing on standard output and one diagnostic
   on standard error.

## Output

Header `value,count`, then the ranked rows. Serialization is owned by FEATURE-CsvOutput.md; this
feature supplies the ordered list of (value, count) pairs as `freq.Top`.

import csv
import io
import os
import tempfile
from collections import Counter

from drydock_go import cli_runner

values = ["delta"] * 4 + ["alpha"] * 3 + ["charlie"] * 3 + ["bravo"] * 2 + ["echo"] + ["foxtrot"] + ["golf"]
with tempfile.TemporaryDirectory() as tmp:
    path = os.path.join(tmp, "data.csv")
    with open(path, "w", newline="") as f:
        w = csv.writer(f)
        w.writerow(["k"])
        for v in values:
            w.writerow([v])
    code, out, err = cli_runner("--freq", "k", path)
print(out)
print(err)
assert code == 0
rows = list(csv.reader(io.StringIO(out)))
assert rows[0] == ["value", "count"]
counts = Counter(values)
ranked = sorted(counts.items(), key=lambda kv: (-kv[1], kv[0]))[:5]
assert rows[1:] == [[v, str(c)] for v, c in ranked]

# FEATURE: CSV Output

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Write profile and frequency results as RFC 4180 CSV with newline line endings, only on success. |
| Depends On  | FEATURE-Counts.md, FEATURE-MinMax.md, FEATURE-NumericStats.md, FEATURE-Frequencies.md, FEATURE-ColumnSelect.md |
| Provides    | output.WriteProfile, output.WriteFreq |
| Consumes    | profile.Counts, profile.MinMax, profile.NumericStats, freq.Top |

## Questions

- None.

## Purpose

Serialize the profile and frequency results to standard output.

## Behavior

1. Profile output has the header `column,type,rows,nulls,distinct,min,max,sum,mean,median`, then
   one row per column in file order, or the single row of the column named by `--column`.
2. Frequency output has the header `value,count`, then the ranked rows.
3. Writing uses `encoding/csv` with `UseCRLF` false, so every line ends with `\n`. A field
   containing a comma, a double quote, or a newline is quoted as RFC 4180 specifies.
4. Output is buffered and written to standard output only when the whole command succeeds. A
   failing command writes nothing to standard output and one diagnostic line to standard error
   naming the file and, for a rejected record, its line number.
5. Empty statistic fields are written as empty strings.

## Programmatic Acceptance
