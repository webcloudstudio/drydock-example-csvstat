<requirement name="count-fields" stories="row-counts">
`rows` | Number of data records. `nulls` | Number of null values. `distinct` | Number of different non-null values, compared as exact strings after trimming.
</requirement>
<requirement name="min-max-fields" stories="min-max">
`min`, `max` | `integer`: the smallest and largest value as an integer. `number`: as a decimal. `date`: earliest and latest. `boolean`: `false` if any value is false, else `true`; `true` if any value is true, else `false`. `text`: smallest and largest by byte value. `empty`: empty.
</requirement>
<requirement name="numeric-stat-fields" stories="numeric-stats">
`sum` | `integer`: the integer total. `number`: the decimal total. Otherwise empty. `mean` | `integer` and `number`: total divided by non-null count. Otherwise empty. `median` | `integer` and `number`: the middle value of the sorted non-null values, or the mean of the two middle values when the count is even. Otherwise empty.
</requirement>
<requirement name="decimal-formatting" stories="numeric-stats,min-max">
**Decimals.** Every `number` `min`, `max`, and `sum`, and every `mean` and `median`, is written with exactly two decimal places, rounded half away from zero from the exact value, with a leading `-` when negative and no thousands separator: `1012.50`, `-12.21`, `0.00`. Integer `min`, `max`, and `sum` are written as plain integers.
</requirement>
<requirement name="frequency-output" stories="frequencies,csv-output">
Header `value,count`, then one row per distinct non-null value of the column, ordered by count descending, then value ascending by byte value, at most `--top` rows. Null values are not listed. A column with no non-null values writes only the header.
</requirement>
<requirement name="output-format" stories="csv-output">
CSV on standard output with `\n` line endings. A field that contains a comma, a double quote, or a newline is quoted as RFC 4180 specifies; Go's `encoding/csv` writer produces this format.
</requirement>
