# ARCHITECTURE: CsvStat

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Module layout, package boundaries, and exit-code contract for the csvstat command-line CSV profiler. |
| Depends On  | None |
| Provides    | cli.Run, cmd/csvstat |

## Questions

- None.

## Purpose

csvstat is a single-pass command-line tool. It reads one CSV file, validates it, infers column types, and writes either a column profile or a value-frequency list as CSV on standard output. It has no persistence, network use, or configuration file.

## Technology Stack

Derived from `TECHNOLOGY_STACK.md`:

- Go 1.22 or newer, standard library only, no third-party modules. The root `go.mod` declares no requirements.
- `go test` with `go vet` behind `bin/test.sh`.
- CSV read and written through `encoding/csv`.
- POSIX sh for `bin/test.sh` and the supplied grader `sources/run.sh`.

## Module Layout

```text
go.mod                    module csvstat, go 1.22 or newer, no require lines
cmd/csvstat/main.go       package main; calls cli.Run and passes the result to os.Exit
internal/cli              Run(args []string, stdout, stderr io.Writer) int
internal/reader           Read, Trim, IsNull, rejection checks
internal/typing           Infer, IsDate
internal/profile          Counts, MinMax, NumericStats
internal/freq             Top
internal/output           WriteProfile, WriteFreq
bin/test.sh               go vet ./... then go test ./...
```

Only `main` calls `os.Exit`. `cli.Run` uses a local `flag.FlagSet` with `flag.ContinueOnError` and is tested with `bytes.Buffer` writers.

## Exit Codes

| Code | Meaning |
|---|---|
| 0 | Success |
| 1 | The file cannot be opened or read |
| 2 | Usage error |
| 3 | Rejected input: empty file, empty or repeated header name, ragged record, or an absent column name |

A failing command writes nothing to standard output and one or more diagnostic lines to standard error. Output is buffered and written only on success.

## Module Ownership

| Boundary | Owner | Notes |
|---|---|---|
| Persistence | none | No persistent state exists. |
| Configuration | none | Behavior is set only by command-line options. |
| File access | internal/cli | Opens the named file read-only and hands a reader to internal/reader. |
| External services | none | No network use. |

## Constraints

- Statistics (sum, mean, median) are computed with `math/big` exact values and rounded once, half away from zero, when written.
- Application code never reads `sources/run.sh` or any supplied data file and never embeds an expected value.

# FEATURE: CSV Reading

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Read a UTF-8 RFC 4180 CSV stream with encoding/csv into a header, data records, and record line numbers. |
| Depends On  | ARCHITECTURE.md |
| Provides    | reader.Read |

## Questions

- None.

## Purpose

`internal/reader` parses the input file into a table that later stories trim, validate, type, and profile.

## Interface

```text
package reader

type Table struct {
    Header []string   // first record
    Rows   [][]string // later records, in file order
    Lines  []int      // 1-based input line on which each row starts; len(Lines) == len(Rows)
}

func Read(r io.Reader) (Table, error)
```

## Behavior

- Parsing uses `encoding/csv` with `FieldsPerRecord = -1`, so a record whose field count differs from the header is returned as-is. Ragged detection belongs to the reject-malformed story.
- The first record is the header; every later record is a data row. Line numbers come from the csv reader's field positions.
- A quoted field containing a comma, a quote, or a newline stays inside one value.
- An empty input returns a zero Table and a nil error; the caller rejects it.
- Bytes that are not valid UTF-8 are not a rejection condition; they are read as `encoding/csv` reads them.
- A syntax error reported by `encoding/csv` is returned unchanged; the caller chooses the exit status.
- Values are returned untrimmed here; trimming is the null-trim story.

## Test Names

The build agent writes these tests in `internal/reader` with exactly these names:

- `TestReadHeaderThenRows`: first record is the header and later records are rows, in order.
- `TestReadQuotedComma`: a quoted field containing a comma is one value.
- `TestReadInvalidUTF8NotRejected`: a field containing a byte that is not valid UTF-8 is read with a nil error.
- `TestReadRaggedRecordReturned`: a record with an extra field is returned unchanged with a nil error.
- `TestReadLineNumbers`: Lines holds the starting line of each row, counting a multi-line quoted field correctly.
- `TestReadEmptyInput`: empty input returns an empty Table and a nil error.

# FEATURE: Null and Trim

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Trim header names and values of surrounding spaces and classify null values. |
| Depends On  | FEATURE-CsvReading.md |
| Provides    | reader.Trim, reader.IsNull |

## Questions

- None.

## Purpose

Every later rule operates on trimmed values and on the null classification defined here.

## Interface

```text
package reader

func TrimTable(t Table) Table   // trims every header name and every value
func Trim(s string) string      // removes leading and trailing spaces
func IsNull(s string) bool      // s is already trimmed
```

## Behavior

- `Trim` removes leading and trailing space characters (U+0020) only, and is applied to every header name and every value before any other rule.
- `IsNull` is true when the trimmed value is empty, or equals `NA`, `N/A`, or `NULL` ignoring case. Every other value is non-null.
- A value consisting only of spaces trims to empty and is therefore null.
- Distinctness elsewhere is compared on the trimmed string, so a padded value and its trimmed form are the same value.

## Test Names

The build agent writes these tests in `internal/reader` with exactly these names:

- `TestTrimSpaces`: leading and trailing spaces are removed and interior spaces are kept.
- `TestIsNullSpellings`: empty, NA, N/A, NULL in upper, lower, and mixed case are null; a near miss such as "NAN" or "N A" is not.
- `TestTrimBeforeNull`: a value of only spaces is null after trimming.
- `TestTrimTableHeaderAndRows`: TrimTable trims header names and every row value and preserves Lines.
