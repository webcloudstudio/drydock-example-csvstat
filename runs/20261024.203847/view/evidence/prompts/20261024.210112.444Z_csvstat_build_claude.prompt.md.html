## 2. Shell Scripts (bin/ Directory)

### Script Template

```bash
#!/bin/bash
# CommandCenter Operation
# Name: Human Readable Name
# Type: daemon|batch
# Port: 8000

# --- Standard Preamble ---
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(cd "$SCRIPT_DIR/.." && pwd)"
LOG_DIR="$PROJECT_DIR/data/logs"
mkdir -p "$LOG_DIR"

TIMESTAMP=$(date '+%Y-%m-%d_%H%M%S')
SCRIPT_NAME=$(basename "$0" .sh)
LOG_FILE="$LOG_DIR/${SCRIPT_NAME}_${TIMESTAMP}.log"

echo "=== $SCRIPT_NAME started at $(date '+%Y-%m-%d %H:%M:%S') ===" | tee "$LOG_FILE"

echo "---" | tee -a "$LOG_FILE"
```

# FEATURE: CSV Reading

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Read a UTF-8 RFC 4180 CSV stream with encoding/csv into a header, data records, and record line numbers. |
| Depends On  | ARCHITECTURE.md |
| Provides    | reader.Read |

## Purpose

`internal/reader` parses the input file into a table that later stories trim, validate, type, and profile.

## Interface

```text
package reader

type Table struct {
    Header []string   // first record
    Rows   [][]string // later records, in file order
    Lines  []int      // 1-based input line on which each row starts; len(Lines) == len(Rows)
}

func Read(r io.Reader) (Table, error)
```

## Behavior

- Parsing uses `encoding/csv` with `FieldsPerRecord = -1`, so a record whose field count differs from the header is returned as-is. Ragged detection belongs to the reject-malformed story.
- The first record is the header; every later record is a data row. Line numbers come from the csv reader's field positions.
- A quoted field containing a comma, a quote, or a newline stays inside one value.
- An empty input returns a zero Table and a nil error; the caller rejects it.
- Bytes that are not valid UTF-8 are not a rejection condition; they are read as `encoding/csv` reads them.
- A syntax error reported by `encoding/csv` is returned unchanged; the caller chooses the exit status.
- Values are returned untrimmed here; trimming is the null-trim story.

## Test Names

The build agent writes these tests in `internal/reader` with exactly these names:

- `TestReadHeaderThenRows`: first record is the header and later records are rows, in order.
- `TestReadQuotedComma`: a quoted field containing a comma is one value.
- `TestReadInvalidUTF8NotRejected`: a field containing a byte that is not valid UTF-8 is read with a nil error.
- `TestReadRaggedRecordReturned`: a record with an extra field is returned unchanged with a nil error.
- `TestReadLineNumbers`: Lines holds the starting line of each row, counting a multi-line quoted field correctly.
- `TestReadEmptyInput`: empty input returns an empty Table and a nil error.

| Depends On  | FEATURE-CsvReading.md |

## Purpose

Every later rule operates on trimmed values and on the null classification defined here.

## Interface

```text
package reader

func TrimTable(t Table) Table   // trims every header name and every value
func Trim(s string) string      // removes leading and trailing spaces
func IsNull(s string) bool      // s is already trimmed
```

# FEATURE: Type Inference

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Infer each column's type among integer, number, boolean, text, and empty from its non-null values. |
| Depends On  | FEATURE-NullTrim.md, ARCHITECTURE.md |
| Provides    | typing.Infer |
| Consumes    | reader.IsNull, reader.Trim |

## Purpose

Give every column a type so later stories choose the right min, max, and numeric statistics.

## Behavior

- Inference runs over the trimmed, non-null values of one column. Null values never influence the type.
- A column takes the first of `integer`, `number`, `date`, `boolean`, `text` that every non-null value satisfies. A column with no non-null value is `empty`.

- `boolean`: every value equals `true` or `false`, ignoring case.
- `text`: anything else.

- `typing.Infer(values []string) string` takes already-trimmed values, skips nulls via `reader.IsNull`, and returns the type token.
- The profile output writes the token in the `type` column.

# FEATURE: Frequencies

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | List the most frequent non-null values of one column with --freq, ordered by count then byte value. |
| Depends On  | FEATURE-NullTrim.md, FEATURE-CliOptions.md |
| Provides    | freq.Top |
| Consumes    | reader.Trim, reader.IsNull, --freq, --top |

## Purpose

With `--freq <name>`, csvstat lists the most frequent values of the named column instead of
profiling. The command is `csvstat --freq <name> [--top <n>] <file>`.

## Behavior

1. The column is found by exact, case-sensitive comparison against the trimmed header names.
2. Each value is trimmed before counting. Null values (empty, `NA`, `N/A`, `NULL` ignoring case)

3. One row is produced per distinct non-null value, with its count.
4. Rows are ordered by count descending, then by value ascending by byte value.
5. At most `--top` rows are returned. `--top` defaults to 5 and is a positive integer.

7. A column name absent from the header exits 3 with nothing on standard output and one diagnostic

feature supplies the ordered list of (value, count) pairs as `freq.Top`.

## Purpose

`bin/test.sh` is the single project test entry point. It is written in POSIX sh.

## Behavior

- The script resolves the application root from its own location (the parent of the directory holding the script), changes into it, and does not depend on the caller's working directory.
- It runs `go vet ./...`, then `go test ./...`.
- It exits zero only when both commands pass; a failure of either exits non-zero. It must not mask the first failure.
- It uses no bash-only syntax.
- The application's own tests are written by the build agent beside the code and cover each type, each statistic, null handling, rounding, each output form, and each exit code using files written by the tests.
