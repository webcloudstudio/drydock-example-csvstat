# FEATURE: Profile Output

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Write the per-column profile of a CSV file as RFC 4180 CSV when neither --column nor --freq is given. |
| Depends On  | FEATURE-DecimalFormat.md, FEATURE-RowCounts.md, FEATURE-Arguments.md, FEATURE-CsvReading.md |
| Provides    | csvstat <file> |
| Consumes    | csvdata.Read, profile.InferType, profile.Counts, profile.FormatDecimal, cli.ParseArgs |

## Questions

- None.

## Purpose

`csvstat <file>` profiles every column of the file. The output is CSV on standard output with
the header `column,type,rows,nulls,distinct,min,max,sum,mean,median`, followed by one row per
column in file order. Line endings are `\n`.

## Behavior

- The command reads the file, trims, rejects malformed input, infers each column's type, and
  computes the counts and statistics defined by the stories it consumes.
- The output is built in memory and written to standard output only after every column has been
  computed, so a failing command writes nothing to standard output.
- Output uses Go's `encoding/csv` writer with `UseCRLF` off, so a field containing a comma, a
  double quote, or a newline is quoted as RFC 4180 specifies.
- A header-only file produces one row per header column with type `empty`, `rows` 0, and every
  other field zero or blank.
- Integer `min`, `max`, and `sum` are plain integers. Number `min`, `max`, and `sum`, and every
  `mean` and `median`, carry exactly two decimals produced by `profile.FormatDecimal`.
- Exit status is 0 on success; a rejected file exits 3 with empty standard output.

## Programmatic Acceptance

=== AC profile-output-columns ===
Intent: The profile has the declared header and one row per column in file order, with types, counts, integer sum, and decimal sum and mean derived from the input.
Requires: executable=go; scope=test

import csv
import io
import os
import tempfile
from decimal import Decimal, ROUND_HALF_UP
from drydock_go import cli_runner

rows = [["id", "label", "price"], ["1", "a", "1.50"], ["2", "b", "2.25"], ["4", "c", "3.00"]]
with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "in.csv")
    with open(path, "w", newline="", encoding="utf-8") as f:
        csv.writer(f, lineterminator="\n").writerows(rows)
    code, out, err = cli_runner(path)
print(out)
print(err)
assert code == 0, code
parsed = list(csv.reader(io.StringIO(out)))
header = ["column", "type", "rows", "nulls", "distinct", "min", "max", "sum", "mean", "median"]
assert parsed[0] == header
body = parsed[1:]
assert [r[0] for r in body] == rows[0]
data = rows[1:]
assert all(r[2] == str(len(data)) for r in body)
assert all(r[3] == str(0) for r in body)
assert [r[1] for r in body] == ["integer", "text", "number"]
ids = [int(r[0]) for r in data]
assert body[0][7] == str(sum(ids))
assert body[0][5] == str(min(ids)) and body[0][6] == str(max(ids))
q = Decimal("0.01")
mean = (Decimal(sum(ids)) / len(ids)).quantize(q, rounding=ROUND_HALF_UP)
assert body[0][8] == str(mean)
prices = [Decimal(r[2]) for r in data]
assert body[2][7] == str(sum(prices).quantize(q, rounding=ROUND_HALF_UP))
assert body[1][7] == "" and body[1][8] == "" and body[1][9] == ""
=== END AC profile-output-columns ===

# FEATURE: Frequency Count

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Count and order the distinct non-null values of one column for frequency output. |
| Depends On  | FEATURE-NullValues.md, FEATURE-InputRejection.md |
| Provides    | freq.Count |
| Consumes    | csvdata.Read, csvdata.IsNull |

## Questions

- None.

## Purpose

`internal/freq` counts the trimmed non-null values of a named column and returns them in listing
order. The listing is CSV with header `value,count`.

## Behavior

- Values are trimmed before counting, so padded spellings count together. Comparison is by exact
  string after trimming.
- Null values (empty, `NA`, `N/A`, `NULL` ignoring case) are not listed and not counted.
- Order is count descending, then value ascending by byte value.
- A column with no non-null values produces only the header row.
- A header-only file produces only the header row.
- Output is written with `encoding/csv`, so a value containing a comma or quote is quoted.
- Rejected input (ragged, empty, bad header) exits 3 with empty standard output.

## Programmatic Acceptance

=== AC freq-count-ordering ===
Intent: Values are listed by count descending then by byte value ascending, with counts matching the input.
Requires: executable=go; scope=test

import csv
import io
import os
import tempfile
from collections import Counter
from drydock_go import cli_runner

assert parsed[1:] == [[k, str(n)] for k, n in ordered]

# FEATURE: Frequency Limit

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Limit the number of frequency rows with --top, defaulting to five. |
| Depends On  | FEATURE-FreqCount.md |
| Provides    | freq.Top |
| Consumes    | freq.Count |

## Questions

- None.

## Purpose

After the frequency listing is ordered, at most `--top` rows are written. `--top` is a positive
integer and defaults to 5 when not given.

## Behavior

- The limit applies after ordering, so the rows listed are the first N of the full ordered list.
- A limit larger than the number of distinct values lists every value.
- The header `value,count` is always written on success.
- Validation of `--top` (non-positive, non-integer, without `--freq`) belongs to the usage-errors
  story and exits 2.

## Programmatic Acceptance

# FEATURE: Usage Errors

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Reject malformed command-line arguments with exit status 2 and a single usage line on standard error. |
| Depends On  | FEATURE-Arguments.md |
| Provides    | exit code 2 |
| Consumes    | cli.ParseArgs |

## Questions

- None.

## Purpose

Malformed invocations exit 2, write nothing to standard output, and write one diagnostic line to
standard error that shows the two command forms:

```text
csvstat [--column <name>] <file>
csvstat --freq <name> [--top <n>] <file>
```

## Behavior

Exit 2 for each of:

- no file argument
- more than one file argument
- an unknown option
- an option given without its value
- `--top` that is not a positive integer (zero, negative, or non-numeric)
- `--top` without `--freq`
- `--column` together with `--freq`
- a repeated option

Usage errors are decided from the arguments alone, before the file is opened, and exit 2 even when
the file exists and is valid.

## Programmatic Acceptance

=== AC usage-errors-exit-two ===
Intent: Every malformed argument form exits 2 and writes nothing to standard output.
Requires: executable=go; scope=test

import csv
import os
import tempfile
from drydock_go import cli_runner

rows = [["qty", "sensor"], ["1", "east"], ["2", "west"]]
with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "in.csv")
    other = os.path.join(d, "other.csv")
    for p in (path, other):
        with open(p, "w", newline="", encoding="utf-8") as f:
            csv.writer(f, lineterminator="\n").writerows(rows)
    cases = [
        [],
        [path, other],
        ["--frobnicate", path],
        ["--column"],
        ["--freq"],
        ["--freq", "sensor", "--top"],
        ["--freq", "sensor", "--top", "0", path],
        ["--freq", "sensor", "--top", "-1", path],
        ["--freq", "sensor", "--top", "abc", path],
        ["--top", "3", path],
        ["--column", "qty", "--freq", "qty", path],
    ]
    for args in cases:
        code, out, err = cli_runner(*args)
        print(args, code)
        print(err)
        assert code == 2, (args, code)
        assert out == "", (args, out)

# FEATURE: Column Profile

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Profile a single named column when --column is given. |
| Depends On  | FEATURE-ProfileOutput.md, FEATURE-UsageErrors.md |
| Provides    | csvstat --column |
| Consumes    | csvstat <file>, exit code 2 |

## Questions

- None.

## Purpose

`csvstat --column <name> <file>` writes the profile header and only the row for the named column.

## Behavior

- The output has the same header and the same row content for that column as the full profile.
- The name is matched exactly and case-sensitively against the trimmed header.
- A name not present in the header exits 3 with empty standard output.
- Rejected input (ragged, empty, bad header) exits 3 with empty standard output.
- `--column` combined with `--freq` is a usage error (exit 2), owned by the usage-errors story.

## Programmatic Acceptance

=== AC column-profile-single-row ===
Intent: --column writes the profile header and exactly one row, equal to that column's row in the full profile.
Requires: executable=go; scope=test

import csv
import io
import os
import tempfile
from drydock_go import cli_runner

rows = [["id", "price", "label"], ["1", "1.50", "a"], ["2", "2.25", "b"], ["4", "3.00", "c"]]
with tempfile.TemporaryDirectory() as d:
    path = os.path.join(d, "in.csv")
    with open(path, "w", newline="", encoding="utf-8") as f:
        csv.writer(f, lineterminator="\n").writerows(rows)
    code_all, out_all, err_all = cli_runner(path)
    assert code_all == 0, code_all
    full = list(csv.reader(io.StringIO(out_all)))
    for name in rows[0]:
        code, out, err = cli_runner("--column", name, path)
        print(out)
        print(err)
        assert code == 0, code
        parsed = list(csv.reader(io.StringIO(out)))
        assert parsed[0] == full[0]
        assert len(parsed) == 2
        assert parsed[1][0] == name
        assert parsed[1] == [r for r in full[1:] if r[0] == name][0]
=== END AC column-profile-single-row ===
