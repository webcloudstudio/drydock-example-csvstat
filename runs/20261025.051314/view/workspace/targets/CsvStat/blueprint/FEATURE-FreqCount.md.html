FEATURE: Frequency Count

FieldValue
Version20261025 V1
DescriptionCount and order the distinct non-null values of one column for frequency output.
Depends OnFEATURE-NullValues.md, FEATURE-InputRejection.md
Providesfreq.Count
Consumescsvdata.Read, csvdata.IsNull

Purpose

internal/freq counts the trimmed non-null values of a named column and returns them in listing order. The listing is CSV with header value,count.

Behavior

  • Values are trimmed before counting, so padded spellings count together. Comparison is by exact

string after trimming.

  • Null values (empty, NA, N/A, NULL ignoring case) are not listed and not counted.
  • Order is count descending, then value ascending by byte value.
  • A column with no non-null values produces only the header row.
  • A header-only file produces only the header row.
  • Output is written with encoding/csv, so a value containing a comma or quote is quoted.
  • Rejected input (ragged, empty, bad header) exits 3 with empty standard output.

Programmatic Acceptance

=== AC freq-count-ordering ===
Intent: Values are listed by count descending then by byte value ascending, with counts matching the input.
Requires: executable=go; scope=test

import csv import io import os import tempfile from collections import Counter from drydock_go import cli_runner

values = ["b", "a", "b", "c", "a", "b", "z", "c", "B", "B"] rows = [["v"]] + [[x] for x in values] with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "in.csv") with open(path, "w", newline="", encoding="utf-8") as f: csv.writer(f, lineterminator="\n").writerows(rows) code, out, err = cli_runner("--freq", "v", path) print(out) print(err) assert code == 0, code parsed = list(csv.reader(io.StringIO(out))) assert parsed[0] == ["value", "count"] counts = Counter(values) ordered = sorted(counts.items(), key=lambda kv: (-kv[1], kv[0].encode("utf-8"))) assert parsed[1:] == [[k, str(n)] for k, n in ordered] === END AC freq-count-ordering ===

=== AC freq-count-nulls-and-trim ===
Intent: Null spellings are omitted and padded values count with their trimmed form.
Requires: executable=go; scope=test

import csv import io import os import tempfile from collections import Counter from drydock_go import cli_runner

values = ["", "NA", "n/a", "NULL", "null", "x", " x ", "y"] rows = [["v"]] + [[x] for x in values] with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "in.csv") with open(path, "w", newline="", encoding="utf-8") as f: csv.writer(f, lineterminator="\n").writerows(rows) code, out, err = cli_runner("--freq", "v", path) print(out) print(err) assert code == 0, code parsed = list(csv.reader(io.StringIO(out))) nulls = {"", "na", "n/a", "null"} counts = Counter(v.strip() for v in values if v.strip().lower() not in nulls) ordered = sorted(counts.items(), key=lambda kv: (-kv[1], kv[0].encode("utf-8"))) assert parsed[1:] == [[k, str(n)] for k, n in ordered] === END AC freq-count-nulls-and-trim ===
