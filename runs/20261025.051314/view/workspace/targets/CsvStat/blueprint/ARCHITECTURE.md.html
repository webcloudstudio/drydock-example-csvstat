Purpose

csvstat is a single Go command-line executable. It reads one CSV file, infers a type for each column, and writes either a column profile or a frequency listing to standard output as CSV. Failures write one diagnostic line to standard error and nothing to standard output.

Module Layout

go.mod                    module csvstat, go 1.22 or newer, no require directive
cmd/csvstat/main.go       package main; calls cli.Run and passes the result to os.Exit
internal/cli              argument parsing, dispatch, exit-code mapping, diagnostics
internal/csvdata          CSV reading, trimming, null recognition, input rejection
internal/profile          type inference, counts, min/max, sum/mean/median, decimal formatting
internal/freq             frequency counting, ordering, limiting
bin/test.sh               POSIX test gate (go vet ./... then go test ./...)
sources/                  read-only scoring assets; never modified

Each internal/ package carries a doc.go declaring its package so the layout exists before any behavior is built.

Entry Contract

cli.Run(args []string, stdout, stderr io.Writer) int is the single entry point. args excludes the program name. Only cmd/csvstat/main.go calls os.Exit; no package under internal/ does. Tests call Run with bytes.Buffer writers.

Standard output is written only on success: output is built in memory and flushed after every check has passed.

Exit Codes

CodeMeaning
0Success
1Operational failure: the file cannot be opened or read
2Usage error: missing or extra file, unknown option, missing option value, non-positive or malformed --top, --top without --freq, --column with --freq
3Rejected input: empty file, empty or repeated header name, ragged or malformed record, or a column name absent from the header

Technical Decisions

  • Sums, means, and medians are computed exactly with math/big and rounded once, half away from zero,

when written.

  • Application code never reads sources/run.sh or any supplied data file and never embeds a statistic,

a type, or a value list. Every value comes from the file examined.

  • Diagnostics go to standard error and are never compared by the grader.

Guardrails

  • Application code never reads sources/run.sh or any supplied data file and never embeds an answer.
  • Use only the Go standard library; add no third-party module.
