FEATURE: Frequency Reports

FieldValue
Version20261022 V1
DescriptionProduce ordered frequency reports for a selected CSV column.
Depends OnFEATURE-CSV-VALIDATION.md
Providesfrequency CSV reports with --top limiting
Consumesvalidated CSV documents and null classification

Purpose

Count normalized non-null values for a named column and emit the requested top-frequency rows.

Behavior

  • Exclude null values.
  • Order by count descending.
  • Break equal-count ties by bytewise ascending value.
  • Apply a positive --top limit, defaulting to five.
  • Emit value,count even when the column has no non-null values.
  • Reject absent columns through the validation contract.

Programmatic Acceptance

=== AC frequency-ordering ===
Intent: Frequency output is valid CSV with the declared value and count columns. import csv import subprocess import tempfile from pathlib import Path

source = "value\na\nb\na\nc\n" with tempfile.TemporaryDirectory() as directory: path = Path(directory) / "input.csv" path.write_text(source) result = subprocess.run( ["go", "run", "./cmd/csvstat", "--freq", "value", str(path)], capture_output=True, text=True ) assert result.returncode == 0 rows = list(csv.DictReader(result.stdout.splitlines())) assert rows assert set(rows[0]) == {"value", "count"} === END AC frequency-ordering ===

=== AC frequency-top-limit ===
Intent: The positive top option limits the number of emitted frequency rows. import csv import subprocess import tempfile from pathlib import Path
