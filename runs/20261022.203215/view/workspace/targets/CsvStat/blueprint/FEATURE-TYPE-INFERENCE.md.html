FEATURE: Type Inference

FieldValue
Version20261022 V1
DescriptionInfer the ordered type of each validated CSV column.
Depends OnFEATURE-CSV-VALIDATION.md
Providesordered column type inference
Consumesvalidated CSV documents and null classification

Purpose

Classify each column using the first applicable type in this order: integer, number, date, boolean, text, or empty.

Rules

  • Integer values match -?[0-9]+.
  • Number values match -?[0-9]+(\.[0-9]+)?.
  • Dates match YYYY-MM-DD and represent real calendar dates.
  • Booleans equal true or false, ignoring case.
  • Null values do not participate in inference.
  • A column with no non-null values is empty.
  • Preserve normalized source strings for later statistics and output.

Programmatic Acceptance

=== AC type-inference-integer ===
Intent: A column containing signed whole numbers is classified as integer. import csv import subprocess import tempfile from pathlib import Path

source = "value\n-2\n0\n17\n" with tempfile.TemporaryDirectory() as directory: path = Path(directory) / "input.csv" path.write_text(source) result = subprocess.run( ["go", "run", "./cmd/csvstat", "--column", "value", str(path)], capture_output=True, text=True ) assert result.returncode == 0 rows = list(csv.DictReader(result.stdout.splitlines())) assert rows[0]["type"] == "integer" === END AC type-inference-integer ===
