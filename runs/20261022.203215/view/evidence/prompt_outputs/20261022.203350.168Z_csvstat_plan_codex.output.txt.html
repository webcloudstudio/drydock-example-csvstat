# FEATURE: Type Inference

| Field       | Value |
|-------------|-------|
| Version     | 20261022 V1 |
| Description | Infer the ordered type of each validated CSV column. |
| Depends On  | FEATURE-CSV-VALIDATION.md |
| Provides    | ordered column type inference |
| Consumes    | validated CSV documents and null classification |

## Questions

- None.

## Purpose

Classify each column using the first applicable type in this order: integer, number, date, boolean, text, or empty.

## Rules

- Integer values match `-?[0-9]+`.
- Number values match `-?[0-9]+(\.[0-9]+)?`.
- Dates match `YYYY-MM-DD` and represent real calendar dates.
- Booleans equal `true` or `false`, ignoring case.
- Null values do not participate in inference.
- A column with no non-null values is `empty`.
- Preserve normalized source strings for later statistics and output.

## Programmatic Acceptance

=== AC type-inference-integer ===
Intent: A column containing signed whole numbers is classified as integer.
import csv
import subprocess
import tempfile
from pathlib import Path

source = "value\n-2\n0\n17\n"
with tempfile.TemporaryDirectory() as directory:
    path = Path(directory) / "input.csv"
    path.write_text(source)
    result = subprocess.run(
        ["go", "run", "./cmd/csvstat", "--column", "value", str(path)],
        capture_output=True, text=True
    )
    assert result.returncode == 0
    rows = list(csv.DictReader(result.stdout.splitlines()))
    assert rows[0]["type"] == "integer"

# FEATURE: Column Statistics

| Field       | Value |
|-------------|-------|
| Version     | 20261022 V1 |
| Description | Compute and serialize exact statistics for profiled CSV columns. |
| Depends On  | FEATURE-TYPE-INFERENCE.md |
| Provides    | profile rows with counts, extrema, sums, means, medians, and CSV serialization |
| Consumes    | validated CSV documents and inferred column types |

## Questions

- None.

## Purpose

Produce the required CSV profile for every column or one selected column, preserving file order and using exact arithmetic.

## Behavior

- Report rows, nulls, distinct values, minimum, maximum, sum, mean, and median.
- Exclude nulls from distinct values and numeric calculations.
- Use integer arithmetic for integer columns.
- Use exact decimal arithmetic for number columns.
- Round decimal outputs once, half away from zero, to exactly two decimal places.
- Use bytewise ordering for text extrema.
- Serialize output with `encoding/csv` and newline line endings.
- A selected column produces only that column's profile row.

## Programmatic Acceptance

# FEATURE: Frequency Reports

| Field       | Value |

| Version     | 20261022 V1 |
| Description | Produce ordered frequency reports for a selected CSV column. |
| Depends On  | FEATURE-CSV-VALIDATION.md |
| Provides    | frequency CSV reports with --top limiting |
| Consumes    | validated CSV documents and null classification |

## Questions

- None.

## Purpose

Count normalized non-null values for a named column and emit the requested top-frequency rows.

## Behavior

- Exclude null values.
- Order by count descending.
- Break equal-count ties by bytewise ascending value.
- Apply a positive `--top` limit, defaulting to five.
- Emit `value,count` even when the column has no non-null values.
- Reject absent columns through the validation contract.
