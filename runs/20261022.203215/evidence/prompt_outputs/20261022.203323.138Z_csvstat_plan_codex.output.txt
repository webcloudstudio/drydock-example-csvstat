# ARCHITECTURE: CsvStat Application

| Field       | Value |
|-------------|-------|
| Version     | 20261022 V1 |
| Description | Defines the Go module, executable boundary, and internal ownership for the csvstat CLI. |
| Depends On  | — |
| Provides    | Go module, ./cmd/csvstat entry point, internal profiling packages |
| Consumes    | — |

## Questions

- None.

## Purpose

CsvStat is a standard-library-only Go command-line application. The executable is built from
`./cmd/csvstat`; reusable behavior belongs in internal packages.

## Module and Boundaries

- `cmd/csvstat` owns process startup and is the only package permitted to call `os.Exit`.
- `internal/cli` owns argument parsing, command dispatch, diagnostics, and exit-code selection.
- `internal/csvstat` owns CSV reading, normalization, validation, type inference, statistics,
  frequencies, and CSV serialization.
- Input is read from the user-supplied file path only.
- Successful reports are written to standard output; diagnostics are written to standard error.

## Technology Stack

- Go 1.22 or newer.
- Standard library only.
- `encoding/csv` for RFC 4180 parsing and output.
- `math/big` or equivalent exact standard-library arithmetic for decimal calculations.
- POSIX shell for the project test launcher.

## Module Ownership

| Boundary | Owner | Allowed low-level APIs |
|---|---|---|
| Process startup | `cmd/csvstat` | `os`, `io`, CLI package |
| CLI behavior | `internal/cli` | `flag`, `os`, `io` |
| CSV and profiling domain | `internal/csvstat` | `encoding/csv`, `math/big`, `time`, standard library |
| Persistent state | None | No persistent state |
| Configuration | None | No configuration store |
| External services | None | No external services |

## Guardrails

- Use only the Go standard library.
- Do not place application logic in `cmd/csvstat`.
- Do not add persistent storage, network services, or third-party dependencies.
- Only the process entry point may terminate the process directly.

# FEATURE: CLI Contract

| Field       | Value |
|-------------|-------|
| Version     | 20261022 V1 |
| Description | Defines csvstat command parsing, option validation, dispatch, and exit-code behavior. |
| Depends On  | ARCHITECTURE.md |
| Provides    | csvstat argument parser and command dispatch |
| Consumes    | Go module, ./cmd/csvstat entry point |

## Questions

- None.

## Command Forms

```text
csvstat [--column <name>] <file>
csvstat --freq <name> [--top <n>] <file>
```

Options precede the single required file argument. `--column` and `--freq` are mutually
exclusive. `--top` is valid only with `--freq` and must be a positive integer.

## Exit Contract

- `0`: successful profile or frequency report.
- `1`: the file cannot be opened or read.
- `2`: malformed arguments, unknown options, missing values, extra files, invalid `--top`, or
  incompatible options.
- `3`: rejected CSV input or a requested column absent from the header.

Failures write no bytes to standard output. Diagnostics are written to standard error.

## Programmatic Acceptance

=== AC cli-contract-usage ===
Intent: Malformed invocations return the usage-error exit status and produce no standard output.

import pathlib
import subprocess
import tempfile

with tempfile.TemporaryDirectory() as directory:
    path = pathlib.Path(directory) / "data.csv"
    path.write_text("a\n1\n", encoding="utf-8")

    cases = [
        ["go", "run", "./cmd/csvstat"],
        ["go", "run", "./cmd/csvstat", str(path), str(path)],
        ["go", "run", "./cmd/csvstat", "--top", "0", str(path)],
        ["go", "run", "./cmd/csvstat", "--top", "2", str(path)],
        ["go", "run", "./cmd/csvstat", "--column", "a", "--freq", "a", str(path)],
        ["go", "run", "./cmd/csvstat", "--unknown", str(path)],
    ]

    for command in cases:
        result = subprocess.run(command, capture_output=True, text=True)
        print(result.stdout)
        print(result.stderr)
        assert result.returncode == 2
        assert result.stdout == ""
=== END AC cli-contract-usage ===

=== AC cli-contract-dispatch ===
Intent: Valid profile and frequency command forms dispatch successfully.

import pathlib
import subprocess
import tempfile

with tempfile.TemporaryDirectory() as directory:
    path = pathlib.Path(directory) / "data.csv"
    path.write_text("a,b\n1,x\n2,y\n", encoding="utf-8")

        text=True,

    print(profile.stdout)
    print(profile.stderr)
    assert profile.returncode == 0
    assert profile.stdout != ""

    frequency = subprocess.run(
        ["go", "run", "./cmd/csvstat", "--freq", "b", "--top", "1", str(path)],
        capture_output=True,
        text=True,
    )
    print(frequency.stdout)
    print(frequency.stderr)
    assert frequency.returncode == 0
    assert frequency.stdout != ""
=== END AC cli-contract-dispatch ===

## User Acceptance

- None.

## Guardrails

- Options must precede the file argument.
- Exactly one file is accepted.
- Never write partial or diagnostic content to standard output on failure.
- Do not silently reinterpret unknown options.

## Help Behavior

The conventional `--help` option succeeds and prints concise usage information to standard error.
The help describes both command forms, `--column`, `--freq`, `--top`, the required file argument,
and the principal exit-code categories.

Usage failures also write a diagnostic and usage text to standard error. Successful CSV output is
never mixed with help or diagnostics.

# FEATURE: CSV Ingestion

| Field       | Value |
|-------------|-------|
| Version     | 20261022 V1 |
| Description | Reads RFC 4180 CSV input and exposes trimmed records in source order. |
| Depends On  | ARCHITECTURE.md |
| Provides    | normalized CSV document model |
| Consumes    | Go module, ./cmd/csvstat entry point |

## Questions

- None.

## Ingestion Rules

- Read the first CSV record as the header.
- Parse RFC 4180 quoting with `encoding/csv`.
- Trim leading and trailing spaces from every header and value after parsing.
- Preserve record order.
- Preserve commas, quotes, and newlines contained in quoted fields.
- Pass the normalized document to validation and profiling.

## Programmatic Acceptance

# FEATURE: CSV Validation

| Field       | Value |
|-------------|-------|
| Version     | 20261022 V1 |
| Description | Validates CSV structure, classifies nulls, and maps rejected and operational failures to exit codes. |
| Depends On  | FEATURE-CSV-INGESTION.md |
| Provides    | validated CSV documents and null classification |
| Consumes    | normalized CSV document model |

## Questions

- None.

## Validation Rules

Reject the input with exit code `3` when:

- The file is empty.
- A header name is empty.
- A header name is repeated.
- A record has a different field count from the header.
- A requested column is absent.

Treat a value as null when it is empty or equals `NA`, `N/A`, or `NULL`, ignoring case, after trimming.
All other values are non-null.

Return exit code `1` when the file cannot be opened or read. Rejected and operational failures write no
standard output.

## Programmatic Acceptance

- Diagnostics may identify the file and rejected record line, but diagnostics are never written to
  standard output.
