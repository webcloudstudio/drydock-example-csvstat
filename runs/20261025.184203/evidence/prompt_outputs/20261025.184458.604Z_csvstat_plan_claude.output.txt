## Declarations

## story foundation
summary:      Stand up the Go module, csvstat entry point, CLI Run skeleton, and bin/test.sh.
type:         foundational
kind:         capability
phase:        1
implements:   ARCHITECTURE.md
stack:        common.md, go.md
provides:     cmd/csvstat, cli.Run, bin/test.sh
acceptance:   yes
instructions: |
  Create go.mod (Go 1.22+, standard library only), cmd/csvstat/main.go that calls
  internal/cli.Run(args, stdout, stderr) and is the only caller of os.Exit, and an
  internal/cli package with Run(args []string, stdout, stderr io.Writer) int.

  Create the POSIX sh launcher bin/test.sh that runs go vet ./... then go test ./... from the
  application root and exits non-zero if either fails.

  Document package boundaries in ARCHITECTURE.md: internal/cli (arguments and exit codes),
  internal/table (CSV reading and validation), internal/profile (types and statistics),
  internal/decimal (exact arithmetic with math/big and formatting). Buffer all stdout so a
  failing command writes nothing to standard output. Never read sources/run.sh or any data file
  from application code.
