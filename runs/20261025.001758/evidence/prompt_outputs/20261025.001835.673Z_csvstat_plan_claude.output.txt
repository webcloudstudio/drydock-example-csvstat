## story foundation
summary:      Stand up the Go module, package layout, and the CLI entry contract everything else builds into.
type:         foundational
kind:         capability
phase:        1
implements:   ARCHITECTURE.md
stack:        common.md, go.md
provides:     go.mod, internal/cli.Run
consumes:
instructions: |
  Create the root go.mod (Go 1.22 or newer, no third-party requirements) and the package layout:
  cmd/csvstat (package main), internal/cli (Run(args []string, stdout, stderr io.Writer) int),
  internal/csvdata (reading, trimming, nulls, validation), internal/infer (type inference),
  internal/profile (statistics), internal/freq (frequency listing), internal/decimal (exact
  rounding). Only main calls os.Exit. Document the exit-code table (0, 1, 2, 3) and the rule that
  a failing command writes nothing to stdout and one diagnostic line to stderr. Create bin/ for
  launchers. Do not read sources/run.sh or any data file from application code.

## story PRF-004
summary:      Compute exact sum, mean, and median for integer and number columns.
type:         service
kind:         capability
phase:        2
implements:   FEATURE-Profile-Numeric-Stats.md
covers:       PRF-004
stack:        go.md
provides:     profile sum, mean, median
consumes:     infer types, internal/decimal
instructions: |
  For integer and number columns only, compute sum, mean (sum over the non-null count), and median
  (middle value of the sorted non-null values, or the mean of the two middle values when the count
  is even) exactly with math/big (big.Rat), over non-null values only. Other types leave the three
  fields empty. Introduce internal/decimal with a formatter that rounds a big.Rat once, half away
  from zero, to two decimal places; mean and median use it for both integer and number columns.
  Integer sum is a plain integer; number sum uses two decimals.
acceptance:   yes
depends:      TYP-005, PRF-002

## story PRF-005
summary:      Format decimals to two places with a single half-away-from-zero rounding.
type:         service
kind:         capability
phase:        2
implements:   FEATURE-Decimal-Rounding.md
covers:       PRF-005
accepts:      st-005
stack:        go.md
provides:     decimal formatting contract
consumes:     internal/decimal
instructions: |
  Make the decimal contract exact and total: round once from the exact value, half away from zero
  (a tie of 0.005 becomes 0.01, -0.005 becomes -0.01), always two decimal places, a leading minus
  only when the rounded value is negative (never -0.00), no thousands separator. Cover values that
  binary floating point rounds wrongly. Number min and max use the same formatter; integer min,
  max, and sum stay plain integers.
acceptance:   yes
depends:      PRF-004
