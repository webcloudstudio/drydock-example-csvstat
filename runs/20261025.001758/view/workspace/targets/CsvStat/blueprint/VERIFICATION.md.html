Purpose

This is the terminal story. Every implementation story has closed before it runs. It adds no application behavior. It confirms that the assembled ./cmd/csvstat builds and that the supplied grader sources/run.sh passes all 22 checks, which are the sole acceptance verdict. It also confirms that bin/test.sh exits zero. The grader is read-only and is executed, never edited. Application code never reads sources/run.sh or the supplied data files.

Assembly

  • sh sources/run.sh is run from the application root. It builds ./cmd/csvstat with go build

and compares exit code and standard output for 22 commands (A1-A4, B1-B3, C1-C5, E1-E4, U1-U6).

  • sh bin/test.sh runs go vet ./... and go test ./....
  • The built executable is exercised directly through drydock_go.cli_runner for one usage error

and one profile of a staged data file.
