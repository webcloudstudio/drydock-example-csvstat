FEATURE: Profile Numeric Stats

FieldValue
Version20261025 V1
DescriptionCompute exact sum, mean, and median for integer and number columns using arbitrary-precision rational arithmetic.
Depends OnFEATURE-Type-Text-Empty.md, FEATURE-Profile-Counts.md
Providesprofile sum, mean, median
Consumesinfer types, internal/decimal

Purpose

Fill the sum, mean, and median fields for columns typed integer or number. All arithmetic is exact (math/big, big.Rat); rounding happens once, when the value is written.

Behavior

  • Only non-null values participate. The count used for the mean is the non-null count.
  • sum: integer columns write the integer total; number columns write the total with exactly two decimal places.
  • mean: sum divided by the non-null count, written with two decimal places for both integer and number columns.
  • median: the middle value of the numerically sorted non-null values, or the mean of the two middle values when the count is even; written with two decimal places for both types.
  • Sorting is numeric, never lexical (9 sorts before 10).
  • For every other type (text, date, boolean, empty) the three fields are empty.
  • internal/decimal provides the formatter that rounds a big.Rat once, half away from zero, to two decimals. Its exact contract is owned by the decimal rounding story.

Programmatic Acceptance

=== AC prf004-integer-stats ===
Intent: Integer columns report the exact integer sum and two-decimal mean and median over non-null values.
Suite: scoped

import csv import io import os import tempfile from fractions import Fraction from drydock_go import cli_runner

def run_profile(columns, *opts): names = list(columns) n = len(columns[names[0]]) buf = io.StringIO() w = csv.writer(buf, lineterminator="\n") w.writerow(names) for i in range(n): w.writerow([columns[c][i] for c in names]) with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "in.csv") with open(path, "w", newline="") as f: f.write(buf.getvalue()) code, out, err = cli_runner(*opts, path) print(out) print(err) assert code == 0, code return {r["column"]: r for r in csv.DictReader(io.StringIO(out))}

def fmt2(fr): scaled = fr * 100 n, d = scaled.numerator, scaled.denominator r = (abs(n) * 2 + d) // (2 * d) sign = "-" if (n < 0 and r != 0) else "" return sign + str(r // 100) + "." + str(r % 100).zfill(2)

def median(vals): s = sorted(vals) m = len(s) return s[m // 2] if m % 2 else (s[m // 2 - 1] + s[m // 2]) / 2

raw = ["3", "1", "2", "10", "NA", ""] vals = [Fraction(v) for v in raw if v not in ("NA", "")] rows = run_profile({"n": raw}) expected_sum = str(int(sum(vals))) expected_mean = fmt2(sum(vals) / len(vals)) expected_median = fmt2(median(vals)) assert rows["n"]["type"] == "integer", rows["n"] assert rows["n"]["sum"] == expected_sum, rows["n"] assert rows["n"]["mean"] == expected_mean, rows["n"] assert rows["n"]["median"] == expected_median, rows["n"] === END AC prf004-integer-stats ===

User Acceptance

  • None.

Guardrails

  • Sums, means, and medians are computed exactly with math/big; never with float64.
  • Round once, at output; never round an intermediate value.
  • Do not hardcode any statistic; every value comes from the file examined.
