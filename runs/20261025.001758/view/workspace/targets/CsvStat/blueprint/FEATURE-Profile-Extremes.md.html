FEATURE: Profile Extremes

FieldValue
Version20261025 V1
DescriptionCompute the min and max of every column according to its inferred type.
Depends OnFEATURE-Decimal-Rounding.md, FEATURE-Profile-Counts.md
Providesprofile min, max
Consumesinfer types, internal/decimal

Purpose

Fill the min and max fields of each profile row. Null values are ignored throughout.

Behavior

  • integer: smallest and largest compared numerically, written as plain integers.
  • number: smallest and largest compared exactly (big.Rat), written with the two-decimal formatter (10.125 is written 10.13).
  • date: earliest and latest.
  • boolean: min is false if any value is false (any letter case), else true; max is true if any value is true, else false. Output is lower case.
  • text: smallest and largest by byte value of the trimmed string (B sorts before a; 10 sorts before 9).
  • empty: both fields are empty.
  • A value that needs quoting (a comma, quote, or newline) is quoted by the shared CSV writer.

import csv import io import os import tempfile from fractions import Fraction from drydock_go import cli_runner

def run_profile(columns, *opts): names = list(columns) n = len(columns[names[0]]) buf = io.StringIO() w = csv.writer(buf, lineterminator="\n") w.writerow(names) for i in range(n): w.writerow([columns[c][i] for c in names]) with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "in.csv") with open(path, "w", newline="") as f: f.write(buf.getvalue()) code, out, err = cli_runner(*opts, path) print(out) print(err) assert code == 0, code return {r["column"]: r for r in csv.DictReader(io.StringIO(out))}

def fmt2(fr): scaled = fr * 100 n, d = scaled.numerator, scaled.denominator r = (abs(n) * 2 + d) // (2 * d) sign = "-" if (n < 0 and r != 0) else "" return sign + str(r // 100) + "." + str(r % 100).zfill(2)

def real(values): return [Fraction(v) for v in values if v.lower() not in ("", "na", "n/a", "null")]

columns = { "ints": ["10", "9", "-3", "NA", "100"], "nums": ["1.5", "-2.25", "10.125", "NULL", "0.0"], "trap": ["9.5", "10.25", "", "N/A", "9.75"], } rows = run_profile(columns) iv = real(columns["ints"]) assert rows["ints"]["type"] == "integer", rows["ints"] assert rows["ints"]["min"] == str(int(min(iv))), rows["ints"] assert rows["ints"]["max"] == str(int(max(iv))), rows["ints"] for name in ("nums", "trap"): vals = real(columns[name]) assert rows[name]["type"] == "number", (name, rows[name]) assert rows[name]["min"] == fmt2(min(vals)), (name, rows[name]) assert rows[name]["max"] == fmt2(max(vals)), (name, rows[name]) === END AC prf003-integer-number ===

User Acceptance

  • None.

Guardrails

  • Number extremes are compared exactly, never through float64, and are written only through internal/decimal.
  • Text comparison is by byte value; do not use locale or case-folding collation.
  • Do not hardcode any extreme; every value comes from the file examined.
