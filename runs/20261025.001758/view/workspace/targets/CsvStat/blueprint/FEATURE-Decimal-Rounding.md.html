FEATURE: Decimal Rounding

FieldValue
Version20261025 V1
DescriptionDefine the exact two-decimal formatting contract that rounds once from the exact value, half away from zero.
Depends OnFEATURE-Profile-Numeric-Stats.md
Providesdecimal formatting contract
Consumesinternal/decimal

Purpose

Make internal/decimal exact and total. Every decimal the tool writes (number sum, every mean, every median, and later number min and max) goes through one formatter.

Behavior

  • Input is an exact big.Rat. The result is rounded once, half away from zero, to exactly two decimal places.
  • A tie rounds away from zero: 0.005 becomes 0.01, -0.005 becomes -0.01, 2.675 becomes 2.68, 1.005 becomes 1.01.
  • A leading - appears only when the rounded value is negative; a value that rounds to zero is written 0.00, never -0.00.
  • No thousands separator, no exponent, always two digits after the point, at any magnitude.
  • Integer min, max, and sum remain plain integers and do not use this formatter.
  • Number min and max use this formatter; they are verified by the extremes story, which is built after this one.

Suite Pattern

The project's own go test suite exercises internal/decimal directly with table tests: ties in both signs, values just below and above a tie, zero, negative values that round to zero, and magnitudes beyond float64.

Programmatic Acceptance

import csv import io import os import tempfile from fractions import Fraction from drydock_go import cli_runner

def run_profile(columns, *opts): names = list(columns) n = len(columns[names[0]]) buf = io.StringIO() w = csv.writer(buf, lineterminator="\n") w.writerow(names) for i in range(n): w.writerow([columns[c][i] for c in names]) with tempfile.TemporaryDirectory() as d: path = os.path.join(d, "in.csv") with open(path, "w", newline="") as f: f.write(buf.getvalue()) code, out, err = cli_runner(*opts, path) print(out) print(err) assert code == 0, code return {r["column"]: r for r in csv.DictReader(io.StringIO(out))}

def fmt2(fr): scaled = fr * 100 n, d = scaled.numerator, scaled.denominator r = (abs(n) * 2 + d) // (2 * d) sign = "-" if (n < 0 and r != 0) else "" return sign + str(r // 100) + "." + str(r % 100).zfill(2)

singles = ["0.005", "-0.005", "0.004", "-0.004", "1.005", "2.675", "-2.675", "0.994", "0.0", "-0.0"] columns = {"c" + str(i): [v] for i, v in enumerate(singles)} rows = run_profile(columns) for i, v in enumerate(singles): name = "c" + str(i) expected = fmt2(Fraction(v)) assert rows[name]["type"] == "number", (name, rows[name]) assert rows[name]["sum"] == expected, (name, v, rows[name]) assert rows[name]["mean"] == expected, (name, v, rows[name]) assert rows[name]["median"] == expected, (name, v, rows[name]) === END AC prf005-ties-and-sign ===

User Acceptance

  • None.

Guardrails

  • Round exactly once, from the exact rational value, half away from zero; never round through float64.
  • Never write -0.00, a thousands separator, or an exponent.
  • Integer min, max, and sum are never passed through the decimal formatter.
