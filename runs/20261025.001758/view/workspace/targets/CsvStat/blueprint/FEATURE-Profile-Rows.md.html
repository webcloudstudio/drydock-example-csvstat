FEATURE: Profile Rows

FieldValue
Version20261025 V1
DescriptionEmit the profile header and one row per column in file order, filling column and rows.
Depends OnARCHITECTURE.md, FEATURE-CSV-Reading.md, FEATURE-Null-Values.md, FEATURE-CSV-Rejection.md, FEATURE-CLI-Option-Validation.md
Providesprofile output header
Consumescsvdata.Read, csvdata.IsNull

Purpose

This is the skeleton of the profile output. Later stories fill the remaining fields, so the output shape is fixed here and never changes.

Behavior

  • Without --freq, standard output is CSV written by one encoding/csv writer with \n line

endings.

  • The first row is the header column,type,rows,nulls,distinct,min,max,sum,mean,median (ten fields).
  • One row follows for each header column, in file order. Every row has ten fields.
  • column is the trimmed header name. rows is the number of data records (not counting the

header), written as a plain integer; a header-only file gives 0 for every column.

  • The fields type, nulls, distinct, min, max, sum, mean and median are owned by

later stories (Type-*, Profile-Counts, Profile-Extremes, Profile-Numeric-Stats). Until a later story is built, the field is written empty. The final application fills all of them.

  • Exit 0 on success.

Programmatic Acceptance

=== AC profile-rows-header-and-columns-in-file-order ===
Intent: The profile starts with the ten-field header and lists one row per input column in file order.

import csv import io import os from drydock_go import cli_runner

data = os.path.abspath(os.path.join("sources", "employees.csv")) with open(data, newline="") as f: source = list(csv.reader(f)) names = source[0] code, out, err = cli_runner(data) print(out) print(err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) assert parsed[0] == ["column", "type", "rows", "nulls", "distinct", "min", "max", "sum", "mean", "median"] assert [row[0] for row in parsed[1:]] == names assert all(len(row) == len(parsed[0]) for row in parsed) === END AC profile-rows-header-and-columns-in-file-order ===

=== AC profile-rows-count-matches-records ===
Intent: The rows field equals the number of data records for every column.

import csv import io import os from drydock_go import cli_runner

for name in ("employees.csv", "sensors.csv", "orders.csv"): data = os.path.abspath(os.path.join("sources", name)) with open(data, newline="") as f: source = list(csv.reader(f)) record_count = len(source) - 1 code, out, err = cli_runner(data) print(out) print(err) assert code == 0 parsed = list(csv.reader(io.StringIO(out))) index = parsed[0].index("rows") assert len(parsed) - 1 == len(source[0]) for row in parsed[1:]: assert row[index] == str(record_count) === END AC profile-rows-count-matches-records ===

User Acceptance

  • None.

Guardrails

  • The header row is fixed; no field is added, removed or reordered by any story.
  • Standard output is written only after the whole file has been read and validated.
  • Application code never embeds a statistic, a type, or a value list.
