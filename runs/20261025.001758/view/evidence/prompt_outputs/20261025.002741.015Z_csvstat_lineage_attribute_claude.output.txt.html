<requirement name="profile-csv-file" stories="PRF-001,PRF-006">
Build a command-line tool that profiles a CSV file. For every column it infers a type and reports
row, null, and distinct counts, the minimum and maximum, and for numeric columns the sum, mean, and
median.
</requirement>
<requirement name="list-frequent-values" stories="FRQ-001,FRQ-002,FRQ-003">
It also lists the most frequent values of one column.
</requirement>
<requirement name="go-stdlib-build" stories="foundation,MOD-001">
Implement in Go 1.22 or newer using only the standard library. The application root is a Go
module, and its executable is the main package at `./cmd/csvstat`.
</requirement>
<requirement name="test-entry" stories="MOD-002">
The completed application provides a POSIX-compatible `bin/test.sh` that runs `go vet ./...` and
`go test ./...` from the application root and exits zero only when both pass.
</requirement>
<requirement name="run-harness-scoring" stories="verification">
`drydock uat` runs `sh sources/run.sh` from the completed application root and takes its exit code and output as the score.
</requirement>
<requirement name="command-arguments" stories="CLI-001,CLI-002">
Options precede the file. Exactly one file is required.
</requirement>
<requirement name="column-option" stories="PRF-006,CLI-003">
Profile only the named column.
</requirement>
<requirement name="read-csv-file" stories="CSV-001">
The file is UTF-8 CSV as RFC 4180 defines it, read with Go's `encoding/csv`. The first record
is the header.
</requirement>
<requirement name="trim-values" stories="CSV-001">
Every header name and every value is trimmed of leading and trailing spaces before any other
rule applies.
</requirement>
<requirement name="reject-malformed-file" stories="CSV-002">
The file is **rejected** when it is empty, when a header name is empty or repeated, or when any
record has a different number of fields from the header.
</requirement>
<requirement name="null-values" stories="CSV-003">
**Null.** A value is null when it is empty, or when it equals `NA`, `N/A`, or `NULL` ignoring
case. All other values are non-null.
</requirement>
<requirement name="type-inference" stories="TYP-001,TYP-002,TYP-003,TYP-004,TYP-005">
A column's type is the first of these that every non-null value satisfies:
</requirement>
<requirement name="empty-column-type" stories="TYP-005">
A column with no non-null values has type `empty`.
</requirement>
<requirement name="profile-output-rows" stories="PRF-001">
Header `column,type,rows,nulls,distinct,min,max,sum,mean,median`, then one row per column in file
order (or the one named by `--column`).
</requirement>
<requirement name="profile-counts" stories="PRF-002">
`rows` | Number of data records. | `nulls` | Number of null values. | `distinct` | Number of different non-null values, compared as exact strings after trimming.
</requirement>
<requirement name="profile-min-max" stories="PRF-003">
`min`, `max` | `integer`: the smallest and largest value as an integer. `number`: as a decimal. `date`: earliest and latest. `boolean`: `false` if any value is false, else `true`; `true` if any value is true, else `false`. `text`: smallest and largest by byte value. `empty`: empty.
</requirement>
<requirement name="numeric-stats" stories="PRF-004">
`sum` | `integer`: the integer total. `number`: the decimal total. Otherwise empty. | `mean` | `integer` and `number`: total divided by non-null count. Otherwise empty. | `median` | `integer` and `number`: the middle value of the sorted non-null values, or the mean of the two middle values when the count is even. Otherwise empty.
</requirement>
<requirement name="decimal-formatting" stories="PRF-005">
**Decimals.** Every `number` `min`, `max`, and `sum`, and every `mean` and `median`, is written with
exactly two decimal places, rounded half away from zero from the exact value, with a leading `-`
when negative and no thousands separator: `1012.50`, `-12.21`, `0.00`. Integer `min`, `max`, and
`sum` are written as plain integers.
</requirement>
<requirement name="frequency-output" stories="FRQ-001,FRQ-002,FRQ-003">
Header `value,count`, then one row per distinct non-null value of the column, ordered by count
descending, then value ascending by byte value, at most `--top` rows. Null values are not listed. A
column with no non-null values writes only the header.
</requirement>
<requirement name="csv-output-format" stories="CLI-004">
CSV on standard output with `\n` line endings. A field that contains a comma, a double quote, or a
newline is quoted as RFC 4180 specifies; Go's `encoding/csv` writer produces this format.
</requirement>
<requirement name="failure-output" stories="CSV-004,CSV-002,CLI-003">
A failing command writes nothing to standard output and one diagnostic line to standard error naming
the file and, for a rejected record, its line number.
</requirement>
<requirement name="exit-codes" stories="CSV-004,CLI-002,CSV-002,CLI-003">
| `0` | Success. | `1` | Operational failure: the file cannot be opened or read. | `2` | Usage error: missing or extra file, unknown option, missing option value, `--top` not a positive integer, `--top` without `--freq`, `--column` with `--freq`. | `3` | Rejected: empty file, empty or repeated header name, ragged record, or a column name that is not in the header.
</requirement>
