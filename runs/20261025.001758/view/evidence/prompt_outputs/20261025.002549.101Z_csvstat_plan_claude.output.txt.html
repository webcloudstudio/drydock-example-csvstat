# FEATURE: Profile Column Option

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Profile a single named column with the --column option. |
| Depends On  | FEATURE-Profile-Extremes.md, FEATURE-CLI-Unknown-Column.md |
| Provides    | csvstat --column <name> <file> |
| Consumes    | column lookup, profile rows |

## Questions

- None.

## Purpose

`csvstat --column <name> <file>` writes the profile header and exactly one row: the row of the
named column. That row is identical to the same column's row in the full profile. An unknown column
name is owned by FEATURE-CLI-Unknown-Column.md (exit 3), and combining `--column` with `--freq` is
owned by FEATURE-CLI-Option-Validation.md (exit 2).

## Behavior

- Output is the header `column,type,rows,nulls,distinct,min,max,sum,mean,median` followed by one
  row for the named column.
- The column is matched by exact trimmed header name.
- The row is computed by the same code path as the full profile, so `rows` still counts every data
  record and every statistic covers the whole column.
- A header-only file with `--column` yields the header and one row with `rows` 0.

## Programmatic Acceptance

# FEATURE: Frequency List

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | List the most frequent non-null values of one column with --freq. |
| Depends On  | FEATURE-CLI-Unknown-Column.md, FEATURE-Null-Values.md |
| Provides    | csvstat --freq <name> <file> |
| Consumes    | column lookup, csvdata.IsNull |

## Questions

- None.

## Purpose

`csvstat --freq <name> <file>` lists the distinct non-null values of the named column with their
counts instead of profiling.

## Behavior

- Output header is `value,count`.
- One row per distinct non-null trimmed value, ordered by count descending, then value ascending by
  byte value.
- Null values (empty, `NA`, `N/A`, `NULL` ignoring case) are never listed.
- Values are trimmed before counting and compared as exact strings, so case differences are
  different values.
- At most 5 rows are written by default; the `--top` option is owned by FEATURE-Frequency-Top.md.
- A column name absent from the header exits 3 through the shared lookup.

## Programmatic Acceptance

=== AC freq-department-order ===
Intent: --freq department on employees.csv lists every distinct value ordered by count descending then value by byte order.

import csv
import io
from drydock_go import cli_runner

def load(path):
    with open(path, newline="", encoding="utf-8") as f:
        rows = list(csv.reader(f))
    return [[c.strip() for c in r] for r in rows]

def is_null(v):
    return v == "" or v.lower() in ("na", "n/a", "null")

def expected(path, col):
    rows = load(path)
    i = rows[0].index(col)
    counts = {}
    for r in rows[1:]:
        if not is_null(r[i]):
            counts[r[i]] = counts.get(r[i], 0) + 1
    return sorted(counts.items(), key=lambda kv: (-kv[1], kv[0].encode("utf-8")))

path = "sources/employees.csv"
col = "department"
code, out, err = cli_runner("--freq", col, path)
print(out)
print(err)
assert code == 0
got = list(csv.reader(io.StringIO(out)))
want = expected(path, col)
assert len(want) <= 5
assert got[0] == ["value", "count"]
assert got[1:] == [[v, str(c)] for v, c in want]
=== END AC freq-department-order ===

# FEATURE: Frequency Top Limit

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Limit the rows of a frequency listing with the --top option. |
| Depends On  | FEATURE-Frequency-List.md |
| Provides    | csvstat --freq <name> --top <n> <file> |
| Consumes    | frequency list |

## Questions

- None.

## Purpose

`--top <n>` limits a `--freq` listing to at most `n` value rows. `n` is a positive integer and
defaults to 5. Rejection of invalid `--top` values (zero, negative, non-numeric, or `--top` without
`--freq`) is owned by FEATURE-CLI-Option-Validation.md and exits 2.

## Behavior

- At most `n` value rows are written after the `value,count` header.
- Rows are the first `n` of the full ordering: count descending, then value ascending by byte value.
- A `n` larger than the number of distinct non-null values writes every value.

## Programmatic Acceptance

# FEATURE: CLI CSV Output

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Write every output form as CSV with RFC 4180 quoting and \n line endings. |
| Depends On  | FEATURE-Profile-Extremes.md, FEATURE-Frequency-List.md |
| Provides    | CSV output format |
| Consumes    | profile output, frequency output |

## Questions

- None.

## Purpose

Profile, `--column`, and `--freq` output all pass through one `encoding/csv` writer, so every
output form quotes and terminates records the same way.

## Behavior

- A field containing a comma, a double quote, or a newline is quoted; embedded quotes are doubled.
- Records end with `\n`, never `\r\n`.
- Parsing standard output with a standards-compliant CSV reader yields the intended field values,
  and every record of one output has the same number of fields as its header.

## Programmatic Acceptance
