# FEATURE: CLI Unknown Column

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Look up a named column by exact trimmed header name and reject a name absent from the header with exit 3. |
| Depends On  | FEATURE-Profile-Rows.md |
| Provides    | column lookup, exit 3 for unknown column |
| Consumes    | csvdata.Read |

## Questions

- None.

## Purpose

`--column <name>` and `--freq <name>` each name a column. This feature provides the single lookup
both options share and the rejection when the name is not a header column.

## Behavior

- The lookup compares the requested name with the trimmed header names by exact string equality.
  It is case-sensitive.
- When the name is absent, the command exits 3, writes nothing to standard output, and writes one
  diagnostic line to standard error naming the file and the column.
- The lookup runs after the file has been read and validated, so a file rejected for another
  reason (empty, bad header, ragged record) reports that rejection first.
- A name that is present proceeds to the normal profile or frequency path with exit 0.
- Usage validation (exit 2) completes before the file is opened and therefore before this lookup.

## Interfaces

- Package `internal/csvdata` (or `internal/cli`) exposes a lookup returning the column index and a
  found flag; `internal/cli.Run` maps "not found" to exit 3.

## Programmatic Acceptance

Requires: executable=go; scope=test

# FEATURE: Type Integer

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Infer integer columns and report the type in the profile row. |
| Depends On  | FEATURE-Profile-Rows.md |
| Provides    | type integer |
| Consumes    | csvdata.IsNull |

## Questions

- None.

## Purpose

Start the first-match type ladder in `internal/infer` and fill the `type` field of each profile row
for integer columns.

## Behavior

- A column is `integer` when it has at least one non-null value and every non-null value, after
  trimming, matches `-?[0-9]+`.
- Null values (empty, `NA`, `N/A`, `NULL` ignoring case) are ignored for inference.
- Leading zeros are allowed. A decimal point, a leading `+`, an exponent, or any other character
  makes the column not integer.
- Columns this story does not classify leave `type` empty until later type stories are built.
  Column with no non-null value is never `integer`.

## Interfaces

- `internal/infer` exposes a classification function over a column's non-null trimmed values; the
  profile writer calls it per column.

## Programmatic Acceptance

Requires: executable=go; scope=test

# FEATURE: Type Number

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Infer number columns for decimal values that are not all integers. |
| Depends On  | FEATURE-Type-Integer.md |
| Provides    | type number |
| Consumes    | csvdata.IsNull |

## Questions

- None.

## Purpose

Extend the type ladder so columns with decimal values are typed `number`.

## Behavior

- A column that is not `integer` is `number` when every non-null trimmed value matches
  `-?[0-9]+(\.[0-9]+)?`.
- A column of only integer-shaped values stays `integer` (first match wins).
- Forms such as `1.`, `.5`, `+1`, `1e3`, and `1,5` are not numbers.
- Null values are ignored; a column with no non-null value is never `number`.

# FEATURE: Type Date

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Infer date columns whose non-null values are real YYYY-MM-DD calendar dates. |
| Depends On  | FEATURE-Type-Number.md |
| Provides    | type date |
| Consumes    | csvdata.IsNull |

## Questions

- None.

## Purpose

Extend the type ladder so columns of calendar dates are typed `date`.

## Behavior

- A column that is neither `integer` nor `number` is `date` when every non-null trimmed value
  matches `YYYY-MM-DD` (four digits, two digits, two digits, hyphen separated) and is a real
  calendar date.
- Validate the shape first, then the calendar with `time.Parse` on the `2006-01-02` layout.
  Leap days are valid only in leap years.
- A single impossible date (for example a February 30) means the column is not `date`; it falls
  through to later types.
- Null values are ignored; a column with no non-null value is never `date`.

# FEATURE: Type Boolean

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Infer boolean columns whose non-null values are true or false in any letter case. |
| Depends On  | FEATURE-Type-Date.md |
| Provides    | type boolean |
| Consumes    | csvdata.IsNull |

## Questions

- None.

## Purpose

Extend the type ladder so columns of true/false values are typed `boolean`.

## Behavior

- A column that is not `integer`, `number`, or `date` is `boolean` when every non-null trimmed
  value equals `true` or `false` ignoring case.
- `1`, `0`, `yes`, `no`, `t`, and `f` are not boolean. A column of `0` and `1` is `integer`
  because the ladder takes the first match.
- Null values are ignored; a column with no non-null value is never `boolean`.
