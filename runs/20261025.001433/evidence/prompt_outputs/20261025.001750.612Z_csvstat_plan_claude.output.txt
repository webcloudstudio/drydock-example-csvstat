## story foundation
summary:      Stand up the Go module, package layout, and architecture for the csvstat CLI.
type:         foundational
kind:         capability
phase:        1
implements:   ARCHITECTURE.md
stack:        go.md, common.md
provides:     go.mod, cmd/csvstat, internal/cli.Run
acceptance:   yes
instructions: |
  Create the root go.mod (Go 1.22 or newer, standard library only, no third-party modules).
  Create cmd/csvstat/main.go, which calls internal/cli.Run(os.Args[1:], os.Stdout, os.Stderr)
  and passes the returned code to os.Exit; only main calls os.Exit. Create the internal/cli
  package with a minimal Run that compiles. Do not read sources/run.sh or any supplied data file
  from application code. Document the package ownership in ARCHITECTURE.md: internal/cli for
  arguments and exit mapping, internal/csvio for reading and validation, internal/profile for
  types, counts, and statistics, internal/decimal for exact arithmetic and formatting.

depends:      foundation
acceptance:   yes
instructions: |
  Parse arguments with a local flag.FlagSet using flag.ContinueOnError. Options precede exactly
  one file. --help writes usage naming both command forms and every option to standard output

  the profile and frequency modes through small interfaces so later stories plug in.

## story input-profile
summary:      Read a well-formed CSV and write the profile header and one row per column.
type:         service
kind:         capability
phase:        1
implements:   FEATURE-CsvReading.md
covers:       INPUT-001
stack:        go.md
provides:     profile output header and rows
depends:      cli-args
acceptance:   yes
instructions: |
  Read the file with encoding/csv; the first record is the header. Write the header
  column,type,rows,nulls,distinct,min,max,sum,mean,median then one row per column in file
  order with the csv writer and \n line endings. Compare bytes as bytes: do not strip a byte-order
  mark and do not reject invalid UTF-8. Set Reader.FieldsPerRecord = -1 so that raggedness is
  checked by the application and not by the reader.

accepts:      st-005
