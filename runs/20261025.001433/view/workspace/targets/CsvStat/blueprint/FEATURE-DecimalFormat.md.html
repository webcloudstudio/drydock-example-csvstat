FEATURE: Decimal Format

FieldValue
Version20261025 V1
DescriptionWrite numeric statistics with exactly two decimals, rounded half away from zero once from the exact value.
Depends OnFEATURE-SumMean.md, FEATURE-Median.md
Providesdecimal formatter for min, max, sum, mean, and median
Consumesexact big.Rat values from sum, mean, median, min, max

Purpose

Numeric statistics are written in one canonical shape. Rounding is performed exactly once, at output, from the exact rational value, so that results are reproducible and independent of binary floating point.

Trigger

Every profile row of an integer or number column writes its numeric cells through this formatter.

Behavior

  • Package: internal/decimal exposes a function taking a *big.Rat and returning a string.
  • For a number column: min, max, sum, mean, and median are two-decimal strings.
  • For an integer column: mean and median are two-decimal strings; min, max, and sum

are plain integers with no decimal point.

  • Two-decimal form: scale the absolute value by 100, round half up on the absolute value

(ties move away from zero) using big.Int arithmetic, then insert the decimal point. There is always at least one digit before the point and exactly two after it.

  • A leading - appears only when the rounded result is non-zero and the value is negative. A

negative value that rounds to zero is written without a sign.

  • No thousands separator, no exponent, no leading +.
  • Rounding is applied once to the exact value; an already rounded value is never rounded again.
  • Non-numeric column types are unaffected and keep their own rules.

Reads

  • Exact big.Rat values produced by the sum, mean, median, and min/max computations.

Writes

  • The numeric cells of the profile row on standard output.

import csv import io import os import tempfile from decimal import Decimal, ROUND_HALF_UP, getcontext from fractions import Fraction

from drydock_go import cli_runner

def fmt(fr): getcontext().prec = 200 d = Decimal(fr.numerator) / Decimal(fr.denominator) return str(d.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))

def median(vals): s = sorted(vals) n = len(s) if n % 2: return s[n // 2] return (s[n // 2 - 1] + s[n // 2]) / 2

def run(text, *opts): with tempfile.TemporaryDirectory() as d: p = os.path.join(d, "data.csv") with open(p, "w", newline="") as fh: fh.write(text) code, out, err = cli_runner(*opts, p) assert code == 0 return code, out, err

cases = [["1.255", "3", "4.5"], ["2.675"], ["-2.675", "-1.004", "10.125"], ["1234567.891", "0.5"]] for vals in cases: text = "v\n" + "\n".join(vals) + "\n" code, out, err = run(text) print(out) print(err) assert code == 0 row = list(csv.reader(io.StringIO(out)))[1] frs = [Fraction(v) for v in vals] assert row[1] == "number" assert row[5] == fmt(min(frs)) assert row[6] == fmt(max(frs)) assert row[7] == fmt(sum(frs)) assert row[8] == fmt(sum(frs) / len(frs)) assert row[9] == fmt(median(frs)) === END AC decimalformat-number-columns ===

import csv import io from decimal import Decimal, ROUND_HALF_UP, getcontext from fractions import Fraction

from drydock_go import cli_runner

def fmt(fr): getcontext().prec = 200 d = Decimal(fr.numerator) / Decimal(fr.denominator) return str(d.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))

def median(vals): s = sorted(vals) n = len(s) if n % 2: return s[n // 2] return (s[n // 2 - 1] + s[n // 2]) / 2

null = ("", "na", "n/a", "null")

def values(path, name): with open(path, newline="") as fh: recs = list(csv.reader(fh)) i = [h.strip() for h in recs[0]].index(name) cells = [r[i].strip() for r in recs[1:]] return [Fraction(c) for c in cells if c.lower() not in null]

for path, name in ( ("sources/employees.csv", "salary"), ("sources/sensors.csv", "temp_c"), ("sources/orders.csv", "unit_price"), ): code, out, err = cli_runner(path) print(out) print(err) assert code == 0 rows = {r[0]: r for r in csv.reader(io.StringIO(out))} frs = values(path, name) row = rows[name] assert row[5] == fmt(min(frs)) assert row[6] == fmt(max(frs)) assert row[7] == fmt(sum(frs)) assert row[8] == fmt(sum(frs) / len(frs)) assert row[9] == fmt(median(frs))

code, out, err = cli_runner("sources/sensors.csv") assert code == 0 rows = {r[0]: r for r in csv.reader(io.StringIO(out))} hum = values("sources/sensors.csv", "humidity") row = rows["humidity"] assert row[5] == str(int(min(hum))) assert row[6] == str(int(max(hum))) assert row[7] == str(int(sum(hum))) assert row[8] == fmt(sum(hum) / len(hum)) assert row[9] == fmt(median(hum)) === END AC decimalformat-fixture-files ===

User Acceptance

  • None.

Guardrails

  • Rounding is performed exactly once, from the exact big.Rat, never from a rounded intermediate.
  • No float32 or float64, and no fmt verb that formats a float, produces a statistic.
  • Output carries no thousands separator, exponent, or + sign.
  • Application code never reads sources/run.sh or any supplied data file and never embeds an answer.
