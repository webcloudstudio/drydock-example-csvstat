Purpose

CsvStat is a single-binary command-line profiler written in Go 1.22 or newer using only the standard library. It reads one CSV file, infers each column's type, reports counts, extremes, and for numeric columns the sum, mean, and median, and can list the most frequent values of one column. There is no persistence and no network I/O.

Module Layout

go.mod                    # module path, go 1.22 or newer, no require lines
cmd/csvstat/main.go       # package main; calls internal/cli.Run and passes the code to os.Exit
internal/cli/             # argument parsing, usage text, dispatch, exit-code mapping
internal/csvio/           # file opening, CSV reading, trimming, validation
internal/profile/         # null rules, type inference, counts, statistics, frequencies
internal/decimal/         # exact arithmetic with math/big and two-decimal formatting
bin/test.sh               # POSIX sh: go vet ./... then go test ./...

internal/cli.Run(args []string, stdout, stderr io.Writer) int is the single entry point. Only cmd/csvstat/main.go calls os.Exit. Behavior is tested with bytes.Buffer.

Exit Codes

CodeMeaning
0Success.
1The file cannot be opened or read.
2Usage error.
3Rejected input: empty file, empty or repeated header name, ragged record, CSV syntax error, or a column name absent from the header.

A failing command writes nothing to standard output and one diagnostic line to standard error. Output is buffered until validation completes.

Constraints

  • Application code never reads sources/run.sh or any supplied data file and never embeds a

statistic, type, or value list.

  • Sums, means, and medians are exact (math/big) and rounded once, half away from zero, at output.
  • Input bytes are compared as bytes; a byte-order mark is not stripped.
