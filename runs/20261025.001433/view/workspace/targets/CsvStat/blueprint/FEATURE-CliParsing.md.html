FEATURE: Command Line Parsing

FieldValue
Version20261025 V1
DescriptionAccept the two csvstat command forms and the --help text, producing a typed request for dispatch.
Depends OnARCHITECTURE.md
Providescsvstat [--column <name>] <file>, csvstat --freq <name> [--top <n>] <file>, csvstat --help
Consumesinternal/cli.Run

Purpose

internal/cli parses arguments with a local flag.FlagSet created with flag.ContinueOnError, whose output is directed to standard error. Options precede exactly one file.

OptionMeaning
--column <name>Profile only the named column.
--freq <name>List the most frequent values of the named column.
--top <n>With --freq, list at most n values; default 5.
--helpWrite usage text to standard output and exit 0.

Behavior

  1. Parsing yields a typed request: mode (profile or frequency), column name, frequency name, top

count, and file path.

  1. --help writes usage text naming both command forms and every option to standard output and

returns 0, writing nothing to standard error.

  1. Profile and frequency modes are dispatched through small interfaces held by Run, so later

stories plug in without changing parsing.

  1. Names given to --column and --freq are kept exactly as given; they are matched later,

exactly and case-sensitively, against trimmed header names.

  1. Usage-error exit mapping is owned by the usage-errors story; this story only has to produce the

request for a well-formed command line.

Required Go Tests

The build adds these tests in internal/cli (names are exact): TestParseHelp, TestParseColumnForm, TestParseFreqForm.
