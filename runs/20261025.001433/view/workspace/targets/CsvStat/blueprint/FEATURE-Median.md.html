FEATURE: Median

FieldValue
Version20261025 V1
DescriptionReport the exact median of the non-null values of integer and number columns.
Depends OnFEATURE-TypesNumeric.md, FEATURE-MinMax.md
Providesprofile field median
Consumescolumn type decision, null rule, trimmed values

Purpose

The median field of a profile row gives the middle of a numeric column's distribution. It is computed from exact values so ordering and the even-count average are never subject to floating point error.

Trigger

Every profile run computes median for every column whose inferred type is integer or number.

Behavior

  • Only non-null values participate (null: empty, NA, N/A, NULL ignoring case, after trimming).
  • Values are parsed into big.Rat and sorted ascending by exact value (Rat.Cmp).
  • With an odd count the median is the middle element.
  • With an even count the median is the mean of the two middle elements, as an exact big.Rat.
  • Both integer and number columns write the median through the decimal formatter, with exactly two

decimals (see FEATURE-DecimalFormat.md).

  • A column of type text, date, boolean, or empty leaves median blank.
  • Input order does not matter; the column is sorted on a copy so no other statistic is disturbed.

Reads

  • The trimmed, null-classified values of the column and its inferred type.

Writes

  • The median cell of the profile row on standard output. No files, no persistence.

import csv import io import os import tempfile from decimal import Decimal, ROUND_HALF_UP, getcontext from fractions import Fraction

from drydock_go import cli_runner

def fmt(fr): getcontext().prec = 200 d = Decimal(fr.numerator) / Decimal(fr.denominator) return str(d.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))

def median(vals): s = sorted(vals) n = len(s) if n % 2: return Fraction(s[n // 2]) return Fraction(s[n // 2 - 1] + s[n // 2], 2)

for vals in ([9, 1, 5, 7, 3], [8, 2, 6, 4], [42], [3, -10, 7, 7, 0, -4]): text = "v\n" + "\n".join(str(v) for v in vals) + "\n" code, out, err = run(text) print(out) print(err) assert code == 0 row = list(csv.reader(io.StringIO(out)))[1] assert row[1] == "integer" assert row[9] == fmt(median(vals)) === END AC median-odd-and-even-integers ===

import csv import io from decimal import Decimal, ROUND_HALF_UP, getcontext from fractions import Fraction

from drydock_go import cli_runner

def fmt(fr): getcontext().prec = 200 d = Decimal(fr.numerator) / Decimal(fr.denominator) return str(d.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))

def median(vals): s = sorted(vals) n = len(s) if n % 2: return s[n // 2] return (s[n // 2 - 1] + s[n // 2]) / 2

null = ("", "na", "n/a", "null")

def values(path, name): with open(path, newline="") as fh: recs = list(csv.reader(fh)) i = [h.strip() for h in recs[0]].index(name) cells = [r[i].strip() for r in recs[1:]] return [Fraction(c) for c in cells if c.lower() not in null]

checks = [ ("sources/sensors.csv", "temp_c"), ("sources/sensors.csv", "humidity"), ("sources/sensors.csv", "reading_id"), ("sources/orders.csv", "qty"), ("sources/orders.csv", "unit_price"), ("sources/employees.csv", "salary"), ] for path, name in checks: code, out, err = cli_runner(path) print(out) print(err) assert code == 0 rows = {r[0]: r for r in csv.reader(io.StringIO(out))} assert rows[name][9] == fmt(median(values(path, name))) === END AC median-fixture-sensors-orders ===
