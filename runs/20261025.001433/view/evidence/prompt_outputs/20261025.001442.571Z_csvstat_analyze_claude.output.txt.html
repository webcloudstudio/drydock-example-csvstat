## Story List

### Feature: Input Reading

| ID | Story | High-level AC |
|---|---|---|
| INPUT-001 | Profile every column of a well-formed CSV file | Stdout is the header `column,type,rows,nulls,distinct,min,max,sum,mean,median`, then one row per column in file order. A quoted field containing a comma is read as one value (RFC 4180 via `encoding/csv`). |
| INPUT-002 | Trim header names and values | Leading and trailing spaces are removed from every header name and value before null, type, distinct, and output rules apply. |
| INPUT-003 | Reject empty files, malformed headers, and ragged records | An empty file, an empty or repeated header name, or a record whose field count differs from the header exits 3 with nothing on stdout and one stderr line naming the file and line number. |

### Feature: Profile Counts

| ID | Story | High-level AC |
|---|---|---|
| COUNTS-001 | Report rows, nulls, and distinct counts per column | `rows` counts data records. `nulls` counts values that are empty or equal `NA`, `N/A`, or `NULL` ignoring case. `distinct` counts distinct non-null values compared as exact trimmed strings. |

### Feature: Column Types

| ID | Story | High-level AC |
|---|---|---|
| TYPES-001 | Infer integer and number column types | `integer` when every non-null value matches `-?[0-9]+`. `number` when every non-null value matches `-?[0-9]+(\.[0-9]+)?` and the column is not integer. |
| TYPES-002 | Infer date column types and reject invalid calendar dates | `date` when every non-null value matches `YYYY-MM-DD` and is a real calendar date. A value such as `2025-02-30` makes the column not date. |
| TYPES-003 | Infer boolean, text, and empty column types | `boolean` when every non-null value equals `true` or `false` ignoring case. `text` when no earlier type fits. `empty` when the column has no non-null value. |

### Feature: Column Statistics

| ID | Story | High-level AC |
|---|---|---|
| STATS-001 | Report min and max for every column type | `integer` as integers. `number` as two-decimal values. `date` as earliest and latest. `boolean` as `false` if any value is false, else `true`, and `true` if any value is true, else `false`. `text` as smallest and largest by byte value. `empty` blank. |
| STATS-002 | Report sum and mean for integer and number columns | `sum` is the total of non-null values. `mean` is the total divided by the non-null count. Other types leave both blank. |
| STATS-003 | Report median for integer and number columns | `median` is the middle sorted non-null value, or the mean of the two middle values when the count is even. Other types leave it blank. |
| STATS-004 | Write numeric statistics with two decimal places | Every `number` min, max, sum, mean, and median, and every integer mean and median, is written with exactly two decimals, rounded half away from zero, with a leading `-` when negative. Integer min, max, and sum are plain integers. |

### Feature: Column Selection

| ID | Story | High-level AC |
|---|---|---|
| SELECT-001 | Profile one named column with `--column` | Output is the profile header and one row for the named column only. |
| SELECT-002 | Reject a named column that is absent from the header | `--column` or `--freq` naming a column not in the header exits 3 with nothing on stdout. |

### Feature: Frequency Listing

| ID | Story | High-level AC |
|---|---|---|
| FREQ-001 | List the most frequent values with `--freq` | Header `value,count`, then distinct non-null values ordered by count descending, then value ascending by byte value. Null values are not listed. An all-null column writes only the header. |
| FREQ-002 | Limit frequency output with `--top` | `--top` defaults to 5 and accepts a positive integer only. `--top` without `--freq` is a usage error. |

### Feature: Command Line Interface

| ID | Story | High-level AC |
|---|---|---|
| CLI-001 | Accept `csvstat [--column <name>] <file>` and `csvstat --freq <name> [--top <n>] <file>` | Options precede exactly one file. `go build ./cmd/csvstat` produces the executable using only the standard library. |
| CLI-002 | Map usage errors to exit code 2 | A missing or extra file, an unknown option, a missing option value, an invalid `--top`, `--top` without `--freq`, or `--column` with `--freq` exits 2 with nothing on stdout. |
| CLI-003 | Map an unreadable file to exit code 1 | A file that cannot be opened or read exits 1 with nothing on stdout. |

## Planning Instructions

### Delivery Shape

CsvStat is a single-binary command-line profiler. The inputs are one CSV file path and optional `--column`, `--freq`, and `--top` options. Profile output is CSV on stdout with `\n` line endings. Diagnostics go to stderr. Exit codes are 0 (success), 1 (unreadable file), 2 (usage), and 3 (rejected input). The application root is a Go module (`go.mod`, go 1.22 or newer) whose main package lives at `cmd/csvstat/`. Module packages below the root are Plan's choice. There is no persistence and no network I/O.

Focused story tests are `go test` cases written with the story. Each feature story runs only its slice with `go test -run <pattern> ./...` from the application root and declares `Suite: scoped`.

QA-002 is the single terminal verification story. It depends on every other story, runs `sh sources/run.sh` unfiltered, and declares `Suite: full`. Its acceptance is that every supplied check passes with zero failures. `run.sh` exposes no scope selector, so no other story executes it.
