Consumesinferred column types, normalized records

Purpose

This capability calculates profile statistics after input normalization and type inference.

For every column it reports row count, null count, distinct non-null values, type-specific minimum and maximum, and numeric sum, mean, and median. Numeric calculations use exact arithmetic and are rounded once, half away from zero, to two decimal places when rendered.

Integer values remain plain integers. Non-numeric sum, mean, and median fields remain empty. Boolean extrema are false when any false value exists and true only when all non-null values are true. Text extrema use bytewise ordering.

=== AC profile-statistics-decimal ===
Intent: Decimal statistics preserve exact values and round mean and median to two places.

import csv import tempfile from decimal import Decimal, ROUND_HALF_UP from pathlib import Path from drydock_go import cli_runner

values = [Decimal("-1.01"), Decimal("-1.00"), Decimal("2.00"), Decimal("2.01")] source = "amount\n" + "\n".join(str(value) for value in values) + "\n" with tempfile.TemporaryDirectory() as directory: path = Path(directory) / "input.csv" path.write_text(source) code, output, error = cli_runner(str(path), package="./cmd/csvstat") assert code == 0 result = list(csv.reader(output.splitlines()))[1] total = sum(values) mean = (total / len(values)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP) median = ((values[1] + values[2]) / 2).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP) assert result[1] == "number" assert result[7] == f"{total:.2f}" assert result[8] == f"{mean:.2f}" assert result[9] == f"{median:.2f}" === END AC profile-statistics-decimal ===
