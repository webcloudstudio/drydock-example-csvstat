Type Inference

For non-null values, classify using this precedence:

  1. integer: -?[0-9]+
  2. number: -?[0-9]+(\.[0-9]+)?
  3. date: a real YYYY-MM-DD calendar date
  4. boolean: true or false, ignoring case
  5. text: any remaining value

A column with no non-null values is empty.
