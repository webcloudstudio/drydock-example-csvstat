## Questions

## Purpose

CsvStat is a standard-library Go command-line pipeline. It reads one RFC 4180 CSV file, normalizes records, validates structure, profiles columns or reports frequencies, renders CSV output, and maps failures to documented exit codes.

## Modules and Boundaries

- `cmd/csvstat`: process startup, argument forwarding, and final `os.Exit`.
- `internal/cli`: flag parsing, command dispatch, diagnostics, and exit-code mapping.
- `internal/csvstat`: CSV loading, normalization, type inference, statistics, frequency aggregation, and rendering.
- `bin/test.sh`: project verification launcher.

Application logic returns values and errors through testable functions. Only the command entry point terminates the process.

## Technology Stack

- Go 1.22 or newer with the standard library only.
- `encoding/csv` for RFC 4180 parsing and output.
- POSIX shell for `bin/test.sh`.
- Exact numeric arithmetic uses standard-library facilities such as `math/big`.

## Contracts

Successful commands write CSV only to standard output. Diagnostics go to standard error. Failed commands write no standard output. Exit codes are 1 for operational failures, 2 for usage failures, and 3 for rejected input.

| Consumes    | ./cmd/csvstat |

## Questions

- None.

## Input Rules

Read UTF-8 CSV with `encoding/csv`. Trim every header and value before null, type, comparison, and aggregation processing. Preserve quoted commas and reject empty files, empty or repeated headers, and records whose field count differs from the header.

## Diagnostics

Rejected records retain their source line information so a diagnostic can identify the file and rejected record line.

## Null and Column Rules

After trimming, a value is null when it is empty or equals `NA`, `N/A`, or `NULL`, ignoring case. Named columns are resolved against the validated, trimmed header. An absent named column is rejected with exit code 3 and no standard output.

# FEATURE: Profile Types

| Field       | Value |
|-------------|-------|
| Version     | 20261023 V1 |
| Description | Infers integer, number, date, boolean, text, and empty column types. |
| Depends On  | FEATURE-CLI-COLUMNS.md |
| Provides    | integer, number, date, boolean, text, and empty inference |
| Consumes    | column lookup, null normalization |

## Questions

- None.

## Type Inference

For non-null values, classify using this precedence:

1. `integer`: `-?[0-9]+`
2. `number`: `-?[0-9]+(\.[0-9]+)?`
3. `date`: a real `YYYY-MM-DD` calendar date
4. `boolean`: `true` or `false`, ignoring case
5. `text`: any remaining value

A column with no non-null values is `empty`.
